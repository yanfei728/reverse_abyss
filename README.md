# Reverse Abyss

一款向上攀爬的 2D 平台跳跃游戏。躲避怪物和机关，收集金币，使用光环清除敌人，也可以用自带编辑器制作并分享关卡。

## 游玩

下载并解压整个项目，使用桌面浏览器打开 `index.html`，点击“开始游戏”。从主界面设置中可以打开编辑器、切换模式、调整视野和换层回血，并使用种子重建塔。

- **简单模式（默认）**：从0层出发，10层可进入休息小屋，抵达20层获胜，没有Boss。
- **经典模式**：挑战40层，在20层和40层迎战Boss；击败20层Boss后按F继续。

| 操作 | 按键 |
|---|---|
| 左右移动 | A / D 或方向键 |
| 跳跃、二段跳 | Space、W 或上方向键 |
| 光环技能 | K |
| 交互、进入塔或小屋 | F |
| 暂停 | P / Esc |

死亡后可以重新挑战同一座塔。游戏设置和浏览器关卡保存在当前浏览器中。

## 关卡编辑器

打开 `editor.html`，或在游戏设置中选择“打开编辑器”。

1. 新建关卡或打开JSON，设置标题、尺寸和难度1–4。
2. 在画布上铺设地块、机关、怪物和金币。标记起点、终点时，点击连续两格的横向云板区域；箭头和坐标会辅助定位。
3. 路径齿轮、移动火球可连续左键放路径节点，右键结束；灵魂放置后再选择移动方向。可以选择内置背景，或从电脑选一张图片作为本关背景。
4. 点击“保存草稿”保存编辑进度；“备份草稿JSON / Ctrl+S”下载文件备份。草稿保存在当前浏览器，不会自动写进项目文件夹。
5. 点击“试玩”，从起点出发，身体完全穿过终点云板即通过。修改地图、难度或背景后，需要重新试玩。
6. 通过后选择**导出到浏览器**，让当前浏览器的正式塔抽取此关；或选择**导出到本地**，选中项目的 `levels` 文件夹，按难度保存JSON并更新关卡清单。

“批量导出到本地”可把浏览器中有效的已发布版本与已通过草稿一起保存到磁盘，原记录继续保留。请在制作关卡时使用的浏览器和同一入口中操作。刷新游戏并开始新塔后，本地导出的关卡才会生效。

若浏览器只能下载关卡包，安装Node.js后，在项目目录运行：

```powershell
node tools/import_level_bundle.mjs "关卡包文件路径.json"
```

也可把已通过的单关JSON放进 `levels/normal/difficulty-1` 至 `difficulty-4` 对应目录，再运行 `node tools/sync_levels.mjs` 更新清单。简单模式抽取难度1、2；经典模式使用全部四档。建议为完成的地图保留JSON文件备份。
