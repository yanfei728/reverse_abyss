# T03～T04：共用运行时与连续世界

共同输入：[世界设计](../design/world-and-gameplay.md)、[数据接口](../design/data-and-interfaces.md)。

## T03 — 共用 GameSession 与时间

前置：T01；T02 可先完成再实施。目标：正式游戏和试玩不再分别定义物理、实体更新与计时。

涉及：game.js、playtest.js、player.js 适配、input.js、session.js、HTML 与 tools/loader.mjs。保留可运行入口，在同一 PR/交付里更新引用顺序。

接口：GameSession.create/step/pause/resume/snapshot/drainEvents/dispose；统一 Actions。DOM 页面负责显示、文件和键盘，核心 Session 负责模拟；不得让正式游戏反过来调用编辑器页面代码。

必须实现：

- 单层目标格式运行样例；正式/试玩用同一 Session；现有玩家物理经适配复用。
- 1/60 秒固定模拟、独立渲染、输入边沿一次消费；后台/失焦暂停并清输入/累积时间。
- 模拟时间而非 Date.now 驱动玩法；active/preview 的时间边界有独立字段。
- 明确会话事件和状态，销毁会话后没有残留循环/监听继续运行。

自动验收：同初始状态与动作序列的正式/试玩快照一致；同模拟时间在不同渲染节奏下位置一致（规定容差）；暂停 30 秒后恢复不补步；一次按键在多子步中不重复施放；销毁后不再发事件。

人工验收：左右、短跳、二段跳、单向平台、弹簧、落脚容错保持原型手感；记录与旧版明显差异，不以“测试都通过”替代手感验收。

不包含：多层连接、生命/技能、完整敌人。单层过关可先产生目标事件，但认证发布由 T06 完成。

## T04 — 可变尺寸连接与三层生命周期

前置：T03。目标：两层连续攀爬，扩大到四个实例验证释放规则；不是先实现完整 40 层。

涉及：World、TowerPlanner 最小 short profile、Camera、Player 碰撞适配、编辑器端口/保护区可视化、当前地图加载入口。

必须实现：

- vertical-v1 接口提案，入口底边/出口顶边的 col 可变；按统一变换移动地形、对象、路线与背景。
- 梯板只生成一份，接口两侧封闭；无需镜像或统一层宽。编辑器自动生成/展示接口禁放区。
- 玩家脚底越线才提交一次入层；同一个 Player 和 RunState 贯穿本局，移动速度与跳跃状态保持。
- 当前 n、上一层 n−1 地形快照、下一层 n+1 非攻击运动；进入 n+1 才释放 n−1。
- next 层预热运动而不攻击，activeTime/超时从激活开始；旧层停止所有实体行为，动态地形显示不复原。
- 相邻层预加载失败时给出明确错误，不能让玩家穿入空世界后偷偷重生；未就绪前停在安全状态。
- 更新相机边界，接缝过渡不淡出、不重建镜头、不因不同宽度跳变。

必须准备的样例：窄→宽、宽→窄、左右偏置接口、不同层高、普通→固定场景；其中一组至少四个连续实例。旧地图不满足接口可继续做草稿，不为了省事强行入池。

自动验收：原点公式正确；对象/路径与地形偏移一致；头先越线不入层；高速穿越仅一次事件；技能占位状态/生命占位状态跨层不清零；在 2 层反复上下运动仍保留 1 层，在 3 层释放 1 层；相同模板实例状态不共享。

人工验收：连续跳过接缝、贴边跳、回落、弹簧越线和镜头反复上下；看得到上一层地形但无法回去；两侧不能绕接口。记录接口尺寸提案是否成立，若调整要同步 profile、校验与设计。

不包含：完整 40 层、完整怪物库、追捕迁移实现、安卓 UI。可用简单移动占位实体验证预热，但占位不得当作 T05 敌人已完成。
