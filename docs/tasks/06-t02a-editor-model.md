## 1. 模型契约

建议由 EditorModel 持有唯一 `data: LevelData`；以下为职责签名，具体命名可在交付说明中映射：

- `fromData(data) -> Result<EditorModel>`：共用 decode/草稿校验，深复制输入；失败不替换当前图。
- `toData() -> LevelData`：返回完整快照，不暴露内部可变引用；不重建成仅含地形的对象。
- `getTile(col,row)` / `setTile(col,row,tileId)`：只改变 terrain.tiles；字符画笔可以保留转换适配，不能再维护第二份可编辑 cells 真值。
- `placeObject(type,col,row)`：已有 S/x/y 画笔映射注册对象与默认参数，生成唯一对象 ID，不把动态对象放回地形字符。
- `resize/translate`：显式操作返回 Result，整次提交或不改数据；对象/路径/起点/装饰及接口 col 的坐标变化由同一模型操作处理。
- `undo/redo`：覆盖全部可编辑内容，不只 cells。使用有容量预算的历史；建议配置最大 100 步、32 MiB，以实际序列化字节估算并淘汰旧历史。这是可调技术提案，不是游戏规则。

所有写操作走统一变更入口，成功后标记 dirty、更新显示、清除 certification。首次内容编辑清除认证，undo/redo 不自动恢复旧通关资格（首版保守策略）；不生成新的 passed。导入时的合法认证可保留显示直到编辑。

扩展地图左侧/顶部时，所有现有格坐标统一平移；路径首点与对象位置仍对应。extensions.legacy 中记录的原文件坐标是历史信息，不猜测其含义并改写；未知参数也不按字段名猜测坐标。

缩小地图会移除非空地形/对象/路径点等内容时，先展示影响并要求编辑器用户明确选择；取消零变更。不能因缩小而悄悄删除对象/路线，也不能用自动夹取坐标把路线挤到边缘。确认后的操作必须能完整撤销。

## 2. 文件与现有 UI

- v2 JSON 直接走 LevelCodec；旧 TXT/旧 JSON 只走显式 LegacyImport 后成为未认证草稿，保留警告和待修复信息。
- 新建时生成稳定合法 id，title 与 id 分开；重命名显示名不自动改逻辑身份，另存为新模板才生成新 id 并清认证。
- 文件导出仅 JSON，调用同步 `LevelCodec.encode()`；失败显示 code/path/message，保留当前图、dirty 与历史；未来 schema 不降级。
- `Ctrl+S` 和原下载入口改成“导出 JSON”。浏览器下载只能显示“已发起导出”，不得确认磁盘已保存或清除未持久保存状态。支持选择磁盘文件时，写入成功与取消结果必须区分。
- 原“保存到游戏”、自动 applyToGamePool 等路径全部从新编辑链路移除或禁用，不能一边保存完整数据，一边仍给旧池写 TXT。
- T02A 期间持久草稿按钮明确标为未接入；T02B 再接保存事务。旧池中的图可以只读读取并迁移到独立工作副本，不回写原内容。
- 新格式试玩/发布按钮明确禁用并解释待后续接入，不通过 exportText→旧 play.html 路线降级试玩。
- 新界面地形预览直接读新网格；已有机关图标与未知对象位置都能看见，未知对象显示占位/不兼容提示，不能从画面和文件里一起消失。
- spawn 为显式数据，可显示/移动；G 旧出口仅作为迁移信息显示，不用随便画一个 G 伪造 vertical-v1 合格接口。完整端口编辑与保护区可视化留 T04；ports=null 的草稿可正常编辑/导出。

## 3. 验收夹具与自动检查

至少准备一张夹具：难度 3、两个有参数对象、一条 pingpong 路线、背景、装饰、extensions、未知对象及其额外字段。初始可含 ports=null 或待修复 pathId，但不能删除这些字段来让测试变简单。

必须验证：

1. 打开→画一格→撤销→重做→导出→重开，除目标地形、派生 hash 与失效认证外，内容等价。
2. 画笔、橡皮、矩形、填充、吸管、已有机关摆放仍可使用；不因兼容画笔而双写地形。
3. 修改参数信息尚无面板时至少保持其原值；未知对象/未知字段/断引用保留，不能自动补成可运行。
4. 失败导入、未来 schema、导出超限、文件取消不替换当前图、不改旧池、不清 dirty。
5. 左/上扩展平移对象/路线/起点/装饰/端口一致；缩小取消无变更，确认后可完整撤销。
6. undo/redo 覆盖对象、引用、元信息，遵守预算，不允许随着拖动画图无限累积全图快照。
7. 不再从 UI 调用旧 TXT 输出、保存即发布或新图转旧试玩路径；检查行为，不能只搜按钮文字证明。

运行专项测试及 `node tools/test_all.mjs`；原有 4 条 floor09/floor11 不属本卡。旧 TXT 导出/保存改池相关测试按新目标替换并逐项说明，保留画图回归，不为增加 PASS 数写重复断言。
