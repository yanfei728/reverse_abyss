## 可玩结果与边界

启动主入口，经过大厅 → 三个普通层 → 休整 → 两阶段 Boss → 胜利；死亡或异常越界回大厅，可重新挑战同一塔。编辑器能制作首版普通模板，保存/恢复、标准试玩通关、发布后被正式短塔抽到。完成后先做 B3 安卓。

使用原生 JS/Canvas、现有物理与素材/占位图；不重写 B1。只做一个角色、三个代表对象与现有机关；不做 40 层、四档内容扩充、遗物、金币、NPC、追捕、服务器或安卓工程。保留原 12 图与未认证迁移草稿，不要求全部迁完才能完成本批。新样例写独立目录，由生成工具接入口。

短塔使用 `short-v1`，位置 0～5 为大厅/普通×3/休整/Boss。工作基线：三个普通槽使用难度 1 池，内容不足允许重复；不为短塔另做四档关卡库。至少提供可由作者实际试玩认证的普通模板及固定场景，展示代表对象；内置认证不得由脚本伪造。

## 批内顺序（不逐项停下等验收）

1. **接正式会话和场景**：主菜单的新短塔入口、不可变 manifest、RunState、输入边沿、死亡/重试与暂停/失焦/后台；复用 GameSession。可先用明确标注的开发短塔贯通，不把草稿混入正式池。

3. **完成休整与 Boss**：一次回复、两生命阶段、三种有预警的基础攻击、停攻清场、暴露命中、胜利/死亡结算。
4. **完成制作与发布**：接口编辑/修复、参数与路径工具、标准试玩、版本绑定回执、原子发布、正式抽选；切换正式入口的数据路径。
5. **整批集成**：制作并实际试玩样例，验证完整通关/死亡流程，修主流程问题，更新启动/操作和真实检查记录。

过程中保留可运行节点/回退提交，必要修复自行连续完成。低影响显示/工具问题集中记录，不变成无限重构；丢工作、错误发布、常用流程崩溃、核心玩法错误必须修。

## 玩法与数值

下列 14/20 秒、跨层规则、Boss 暴露规则、死亡回大厅与异常越界处理是已确认要求；其余初值来自设计提案，可依据实测调整并记录，不冒充用户逐项批准。

- **角色**：100 生命，普通伤害初值 20、无敌初值 1 秒，同一模拟步至多一次受伤。输入初值技能 K、交互 E；保留现有跳跃按键，新增操作写 README。
- **光环**：每次施放生成唯一 castId；持续 14 秒、从施放起冷却 20 秒，开局可用。跨层保留、暂停冻结。普通火球一击消灭后光环继续；地刺/齿轮不可击败；不得攻击 preview 层。初始半径 1.5 格，视觉与判定一致。
- **六类对象**：spring、crumble_door、blink_platform、fireball_static、spike、gear 共用注册参数与实际行为。门触碰消失且本局不恢复；浮石预警/消失初值 0.5/1.6 秒，恢复不夹人；地刺底座实心、伸出部分只伤害；齿轮 loop 含末点到首点的闭环段、pingpong 真正折返，速度按格/秒，不沿用 B1 诊断小点的简化运动。
- **楼层**：preview 加载并运行非攻击运动，不攻击/接触伤害/计超时；入层启用攻击，不补欠账。旧层动态对象清理，仅保留退出时地形/装饰显示快照，到再上一层才释放。跨层不重建 Player，不丢生命/速度/跳跃/技能。
- **接口工具**：入口/出口 col 可编辑，地图宽高自由；4 格开口、3 格安全带沿用工作提案并实际试玩校核。共享校验报告具体冲突格，阻止实心/对象/路线/伤害穿入保护区；连接器只生成一份梯板，封闭旁路。可修复 ports=null 的迁移草稿，保留 retiredPorts 历史，不自动丢记录或认证。
- **休整**：首次进入回复初值 40、封顶 100；按 instanceId 记录一次。无敌人/伤害/超时，不因边界起落重复回复。
- **Boss**：两生命阶段，shielded → exposed → resolving → shielded/defeated。shielded 有激光/弹幕/火球和可读预警；初始护盾阶段 12 秒，其余节奏由实现原型测后给调参表。exposed 停攻、取消待发事件、清全部敌对伤害物/接触伤害，保持至有效命中；至少等满一轮 CD 仍安全。单次 castId 最多打掉一阶段，命中消耗本次光环、不重置冷却；基础移动加光环可可靠碰到 Boss。出口在击败前关闭，死亡优先于同帧胜利。
- **死亡/异常越界（本轮用户确认）**：回大厅，重置本局生命/技能/领取记录与楼层实例，保留相同不可变塔清单以便重试；“重构塔”才重新抽选。替换 B1 的无伤本层 respawn 保险逻辑。越界仍记录诊断，以修边界问题；不能在死亡后生成认证或胜利。

## 数据与模块接口

字段遵循数据设计，不把目标模块写成已完成文件。允许调整内部文件划分；以下所有权/输入输出与失败行为必须一致。

| 模块 | B2 契约 |
|---|---|
| GameSession | 在 B1 核心上增加 `{manifest, templates, rules, mode, profile}` 启动适配；debug/standard/正式短塔都进同一模拟。保留 B1 floors 开发适配或同步迁移调用方，不复制另一套物理/战斗 |
| RunState | 会话唯一可变真值：runId/manifestId/status、当前层、hp/maxHp/invulnerableRemaining、skill 的 activeRemaining/cooldownRemaining/castId、elapsed、visited/claimedRest 集合。Player 不另存一套生命与冷却 |
| FloorInstance / World | instanceId、精确 levelRef、origin、preview/active/snapshot、activeTime、实体与动态地形副本；模板只读。坐标转换与连接器只由 World 管，重复模板实例不共享状态 |
| EntityRegistry / 实体 | 现有 get/list 参数描述共享给 UI/校验/运行时；增加实际创建适配。实体有 ambient/active/draw/dispose 边界，draw 不改玩法状态；已登记但未支持的行为不得静默运行/发布 |
| TowerPlanner | `build({profile,seed,candidates,fixedLevels,fallback,rules}) -> Result<manifest>`；纯函数，不自行读浏览器存储。候选稳定排序再随机，只用兼容的已发布 normal；manifest 按 id+hash 引用不可变内容 |
| ContentRepository | 保留 draftId/revision/Result；增加 `publish({draftId,expectedRevision,receipt})`、`getPublished(levelId,hash)`、`listEligible({difficulty,rules})`。在同一事务重读草稿、校验 revision/hash/规则/回执并写发布版本与池索引；失败旧池不变。同 id 新 hash 保留旧内容，本局模板不受发布影响 |
| PlaytestBridge | 启动登记 sessionId/draftId/revision/hash/rules/profile；只接受对应会话的标准通关结果，校验来源窗口/同源通道。旧回执、过期编辑、debug、死亡/中断不能认证当前草稿 |
| 页面/平台适配 | 键盘转语义动作，pressed 每固定步仅消费一次；显示 HUD/错误/结果，处理草稿文件与回执传递，不单独结算伤害/Boss/通关 |

GameSession 新事件至少覆盖 floorEntered、playerDamaged、skillCast、bossPhaseChanged、dead、won、playtestCompleted；用 runId/sessionId 和单调事件序号识别重复/迟到事件。玩法计时只用模拟时间，受伤/死亡/胜利有一次性结算；无需搭通用消息总线。

## 编辑、标准试玩与发布

- 对象选择/新增/删除/注册参数编辑、路径点/loop/pingpong 工具、端口编辑纳入整份 LevelData 撤销重做；删除被引用路线有明确处理，不静默丢引用。未知内容继续保真草稿，阻止 play/publish。
- 开发试玩仍可用，但明确 debug，不生成标准认证。标准试玩用独立不可变快照、同一 Session 和真实接缝；从生成的入口支撑开始，通过真实出口跨线判定，不能用作者靠近出口的 spawn 跳过关卡。
- 标准 profile `standard-v1` 按既有 B07：100 血、无遗物、无光环、技能剩余冷却 20 秒、无作弊、预热从零。它与正式开局技能可用是不同 profile 的明确规则，不能混淆。
- 通关 Certification/Receipt 使用既有 schema，绑定内容 hash、规则版本/指纹、profile 与 revision；任何内容或规则变化失效。实际采用的物理/技能/攻击/接口/标准配置进入 rulesFingerprint，行为代码改变同步升 rulesVersion。
- 认证不自动发布；明确点击“发布”才事务入池。导入已认证文件校验内容与规则，来源显示 imported-declaration；无匹配认证只保存草稿。继续保留 B1-R1 的异步上下文核对。
- 无可用正式模板时给出明确空池提示和制作入口，不能抽未经认证旧图。可另有清楚标注的开发短塔，供未认证模板调试；不向它发 passed 或把开发状态当正式可发布版本。
