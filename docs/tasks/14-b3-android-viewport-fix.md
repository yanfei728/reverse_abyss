## 1. 先确认原因

- 阅读原两张 [大厅截图](../checks/B3R2-user-android-menu-2026-11-06.jpg)、[布局截图](../checks/B3R2-user-android-layout-2026-11-06.jpg)。区分“菜单在屏外，尚未启动会话”和“已启动但渲染失败”，分别记录 session/菜单状态与控制台异常，不预设素材损坏。
- 采集或提供可复制的最小诊断：应用版本、UA/实际 WebView 提供程序与版本（可取得时）、innerWidth/innerHeight、visualViewport（可用时）、DPR、`CSS.supports` 的 inset/aspect-ratio/min/env 支持、app/wrap/canvas/菜单及设置 box 的 getBoundingClientRect、canvas backing-store 大小、session/status。缺项写未知，不能用 Android 版本代替。
- 优先检查无回退的 `inset:0`、`aspect-ratio`、尺寸循环、短横屏溢出与系统栏。桌面可通过移除相应声明模拟特性缺失，须标为故障注入，不冒充旧引擎/真机实测。浏览器无法启动时记录限制并继续代码排查与打包。

## 2. 恢复可见、可点的完整流程

- app、菜单、暂停/结果/设置/旋转覆盖层有明确包含区域；关键定位提供 top/right/bottom/left 等基础回退，安全区提供零值回退再增强。画布容器有确定 CSS 宽高，不只靠 aspect-ratio/min/env 保证布局，不因不支持其中一个特性把入口排到画布下方。
- 将视口布局、canvas CSS 尺寸、DPR backing-store 分开：从选定的可用区域算展示尺寸，再更新画布像素缓冲；不能写 width/height 后反复撑大容器。保留 16:9 玩法区域/既有坐标约定，留边允许；输入、HUD 和覆盖层使用同一可见区域，不改核心世界坐标或物理来迁就页面。
- 大厅开始按钮必须直接可见可点；短横屏/较大字体时允许说明区域或面板内部滚动，开始、关闭、保存、继续等主操作可达。禁止 overflow:hidden 将必要按钮永久裁掉；布局面板不应挡住所有可拖动按钮且无法关闭。
- 处理冷启动、尺寸变化/旋转、系统栏变化与前后台恢复的重新布局；重复 resize 后尺寸稳定、不积累比例。布局数据继续兼容 schemaVersion 1；旧布局加载后按当前安全区约束，不清存储。
- 菜单、设置、暂停与结果的可见状态由一致规则控制，核对 inline display 与 body class 优先级。打开/关闭布局后能返回正确菜单或暂停状态，保留清输入与不自动恢复模拟的规则。
- 如果初始化或渲染失败，要有可见、可操作的错误信息和取得诊断的途径；不能留下只有黑色区域的不可恢复界面。诊断属于页面/平台层，不把 DOM、UA 或 Capacitor 加进 GameSession。

## 3. 补能发现屏外按钮的验证

复用并改进现有浏览器集成检查，不只断言模块/session 存在。至少对 `short.html?touch=1` 和离线 `www/index.html` 检查：

1. 冷启动：wrap/canvas 在可见视口内且非零，菜单主操作的 rect 在可视/可滚动范围内，中心点命中自身或其后代。启动游戏须用屏幕坐标实际点击/触摸，不能用 DOM `.click()` 绕过布局；正常场景也不能用脚本强改 state 启动。
2. 开始后：菜单消失、HUD 可见、地图与玩家在画布可见区域实际绘制；保留截图/几何记录。用实际输入观察玩家位置变化和抬手停止；不能只验证 session 非空或画布只有背景色。
3. 布局：实际点开、主控件可达，调整/保存/关闭后回到正确界面，重启保留；暂停/继续和返回可操作。
4. 至少覆盖普通横屏、短横屏、与用户截图相近的 16:10 区域；例如 960×540、800×360、960×600 CSS px。DPR 1/2/3 与重复 resize 不应改变 CSS 比例。实际设备的 CSS 视口另行测量，截图像素不能直接当 CSS px。
5. 注入“不支持 inset/aspect-ratio”时验证基础布局仍可用；与现代浏览器正常路径分别记录。故障注入只验证回退，不能代替旧 WebView 或 OPD2101 真机证据。

涉及计算时可加针对边界的单元检查；无需堆函数存在/源码字符串测试。运行必要专项与一次 `node tools/test_all.mjs`，保留真实退出码和 floor09/floor11 旧 4 条诊断。保留 R1 多指释放、R2 重认证、R3 草稿保真、跨层/暂停已有回归，不为测试次数或历史行为重构。
