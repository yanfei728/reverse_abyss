## 用户确认与范围

用户要求移除旧出生点/终点工具、补齐已有怪物摆放、解决尺寸/多余空白导出、改现代极简扁平卡片界面并加深浅模式；随后明确 **Boss与初始大厅不应自由编辑，只补已有怪物**。本卡不增加Boss摆放/参数、自由场景类型切换、新怪物AI、游戏美术、隐藏摇杆或40层。

固定大厅/Boss/休整按现有程序场景管理；普通编辑器打开此类数据为只读预览/原数据导出，不偷转普通图。已实现火球/地刺/齿轮等补齐直接摆放，已有右侧参数能力保留复用。

## 一次实施顺序

1. **清旧工具、连新端点**：移除 P/G 调色板、旧出生点/终点文字及快捷键入口；新普通层从云板 start 生成，不再要求独立 spawn。历史数据保真，端点的添加/清除/检查承接15号卡。固定场景只读保护必须覆盖鼠标、快捷键、导入后的元信息/对象/尺寸修改路径。
2. **对象工具可发现**：左侧地形/机关/怪物分类，EntityRegistry 的 type 驱动图标与点图摆放，不再过滤无 letter 类型；可直接放火球、地刺、齿轮，以及已有弹簧/门/浮石。选中→右侧参数/路径→修改/删除→撤销/重做。没有路径的齿轮给明确问题；未知对象占位保真，不能运行/发布。当前实际未实现的敌人不伪装可用。
3. **地图尺寸与视图分离**：边框/关卡外区域明确；显示真实模型尺寸。关卡20×20时视图再大也导出20×20。自动扩展默认关闭，可明确启用且每笔可撤销；平移/缩放/主题/擦除外部空白不能扩大关卡。尺寸字段先输入再“应用尺寸”，不能只改显示不改模型。
4. **裁外侧空白**：按完整空间内容计算候选矩形，先预览尺寸/偏移再确认；实际修改模型后统一保存/导出，不在导出分支偷偷裁文件。同步端点行列、对象、路径、装饰/活动兼容字段，保留内部空白和历史备份；未知空间语义拒绝自动裁，空图不产生0尺寸。候选编码/校验成功后提交，工作区/内容变化使旧预览失效；取消/失败不动数据，成功整步可撤销并使旧认证失效。原始作者三图副本不裁。
5. **现代工作台**：按设计重组顶栏、分类工具、中央地图、选择属性、尺寸/接口/草稿卡片与底部状态；原生CSS变量/网格/本地字体，扁平中性色和单蓝色强调。主操作保留清晰中文名称，减少历史说明挤占界面；普通表单里隐藏技术 id/hash 到高级区。不引入框架/外部字体CDN，不改变游戏界面。
6. **两主题**：浅/深切换覆盖所有编辑器控件、弹窗和 canvas辅助绘制；设置独立保存，失败如实提示，切换不改地图hash/dirty/认证。检查明暗的文字、网格、边界、选择、错误可辨及首次载入无明显错误主题闪烁。只新增编辑器偏好，不改游戏触控布局设置。
7. **集中集成**：保护B1异步保存/读取/试玩令牌及冲突处理，更新新脚本HTML/loader/浏览器自检；必要专项通过后跑一次 `node tools/test_all.mjs` 保留真实退出码及原4条诊断。最后与15号卡成果同步一次新www/Capacitor并交递增版本APK、哈希/验签/包内对照；编辑器仍不打进手机包。
