## 批内顺序

1. **核实工具链并离线打包**：检查现有 JDK/SDK/Gradle/Android Studio/设备，按所选 Capacitor 官方文档确认兼容组合并锁依赖。采用最小本地资源入口，不依赖电脑服务器或远端 URL。只复制运行所需 HTML/JS/CSS/素材/模板，不把编辑器、Git、报告和测试打入 APK。保留 PC 直接打开/HTTP 路径。
2. **共用语义输入与触控**：先把 short 页的键盘输入与多指触控送入同一动作适配，再完成横屏、安全区域、暂停/菜单/设置及按钮布局保存。
3. **平台生命周期**：后台/失焦/锁屏清输入并暂停；返回键按面板→暂停→应用退出边界处理；恢复等待用户继续，不补现实时间，不叠加动画循环或监听。
4. **JSON 与内容库**：系统选文件、共享编解码/校验、私有仓库、显式加入正式池、系统可访问的导出；保留失败/取消/重复版本与本局快照语义。
5. **集中集成**：PC 发布人工记录、手机离线冷启动与重启、文件完整往返、触控完整短塔/死亡重试；交付 APK 与安装/备份说明。

工具缺失时继续不依赖它的触控/适配/字节检查，准确记录缺少项。不要反复重试同一个失败启动，也不要伪造构建或真机通过。不要擅自进行全局环境改写、删除 SDK、正式签名、上传或商店发布。

## 数据与模块接口

以下是目标契约，可调整文件名；不得写成当前已有 API。新增平台文件放 `js/platform/` 等边界，核心不 import Capacitor/DOM/文件选择 API。

| 模块 | 输入/输出与约束 |
|---|---|
| ActionInput | `setHeld(sourceId,action,down)`、`press(action)`、`releaseSource(sourceId)`、`clearAll()`、`consume()`；返回 held `{left,right,jumpHeld}` 与一次性 pressed `{skill,interact,pause}`。sourceId 区分键盘键与 pointerId，释放一个来源不取消其他仍按住的来源 |
| Session 连接 | held 交给现有 `session.setActions`，技能/交互交给 `pressSkill/pressInteract`；跳跃沿用 Session/Player 的边沿行为；pause 由页面/生命周期适配。一次触摸只产生一次施放边沿，不能每渲染帧重施 |
| PlatformFiles | `pickJSON() -> Promise<Result<{name,text}>>`；`exportJSON({name,text}) -> Promise<Result<{status,location?}>>`。取消用 CANCELLED，不修改仓库；written 仅用于确认完成写入，share-opened 只表示打开系统分享，不能报已保存 |
| PlatformLifecycle | 平台事件转换为 background/foreground/back，订阅可 dispose；后台先清 held/pressed，再 pause；前台仍暂停，用户继续才 resume。菜单没有 Session 时不创建新模拟循环 |
| Repository 导入边界 | `importLevel(json,{rules}) -> Promise<Result<{levelRef,draftId,eligible,issues}>>`（拟定）；先 decode/共享校验/hash，再以明确事务保存。合法草稿可保真留存；不支持/未知内容阻止运行/入池。已认证文件仍核对当前 hash/rules/profile，来源标 imported-declaration，不伪造 local-playtest Receipt |
| ControlLayout | 设置独立于模板/RunState：`{schemaVersion:1,buttons:{[action]:{x,y,size}}}`，x/y 为安全区域内归一化中心，size 为参考短边比例；限定大小与合法范围，旋转/安全区域改变后夹回可见范围，恢复默认明确可用。设置写入失败保留旧值并提示，不冒充保存 |

动作只允许 left/right/jump/skill/interact/pause 等当前需求；左右同时按住采用抵消，松开后保留另一个来源。交互 E 在 B2 是预留，移动端可保留输入入口，但不添加空壳交互系统。

## 触控与生命周期验收规则

- 横屏左右移动在左侧，跳跃/技能在右侧，暂停/菜单/设置不依赖键盘；按钮可调大小/位置、保存、重启恢复及恢复默认。安全区域不遮挡按钮；竖屏可提示旋转，不擅自旋转物理坐标。
- Pointer 或等效事件按触点独立记录；滑出、抬起、cancel、失焦、面板切换、后台都正确释放。一个手指离开跳跃，不会释放另一个手指的移动；长按跳跃不产生无限二段跳。
- Android 返回键先关闭顶层面板，再暂停游玩；菜单态按平台惯例退出，不能直接丢弃正在进行的游戏。暂停/恢复不重建 Player 或 Session。
- 后台、锁屏与文件选择/分享期间冻结模拟；前台保持暂停。光环、CD、机关、Boss、预热时间不变，恢复无追帧补算。重进页面/重试不叠加 rAF 或事件监听。

## 内容与文件验收规则

- 手机与 PC 浏览器内容库各自独立，通过 JSON 转移；不宣称自动同步。离线首次启动可玩明确标注的开发短塔，正式池为空仍提示导入；不能为手机空池自动认证开发模板。
- 未认证/旧规则内容保留为不可选草稿并说明原因。兼容已认证内容显示来源和校验结果，用户明确“加入正式池”后才入池；单纯导入/保存不发布。
- 同 id+hash 幂等；同 id 不同 hash 并存，不能破坏已开局 manifest。取消、错误 JSON、容量/权限/存储失败不改现有池、不清现有内容、不报成功。
- 导出走系统可访问的文件目的地或分享；只写应用私有临时目录不算交付导出。区分写入完成与分享面板已打开，取消可恢复。
- 使用可变尺寸、至少两对象、一条路径、难度/视觉资源引用/extensions/真实认证的文件做 PC→安卓→PC 往返。canonical 数据和 hash 保真，认证来源按导入契约说明；不会为平台转换修改模板坐标或自造新格式。
