## A1：画笔幂等

- 连续按住 S/x/y 在同一格、笔刷重叠、回访同格，不增加重复同类对象，不重置已有对象 ID、参数与未知字段。
- 推荐普通机关画笔同格同类保持原记录，不同类按明确覆盖规则处理并可撤销；未来显式对象工具的叠放能力不由本卡决定。
- 不仅在 UI 单帧跳过重复坐标：矩形/填充/多格笔刷等相同语义也要一致。不能用删掉旧对象重建来制造“只有一个”的假象。
- 回归至少验证同格 60 次、同笔回访、大笔刷重叠、既有自定义参数、对象上限附近、一次拖动一次撤销。浏览器用机关画笔按住至少 1 秒，确认无堆叠。

## A2：失败导入不提交

- fromData/fromJSON 使用共享 decode + validate(draft)；有 error 返回明确 Result，不构造可提交模型；warning 允许保留完整草稿。
- UI 在确认候选可展示前不替换当前图、不清历史或改变视角；失败显示 code/path/message。后续持久保存异步状态不在本卡。
- validate/syncUI 面对缺失 ports.entry/exit 等结构不可抛异常；错误须由共享校验报告，不静默修正输入。
- 回归：缺 entry、缺 exit、错误 col、损坏路径/装饰结构、size 不匹配、非法 tile 等输入失败后，旧数据/历史/dirty/视角完全不变；ports=null、断路径 warning、未知对象仍可编辑和导出。
- 测试完整 UI 路径，而非只验证 decode 返回值；不得捕获异常后照样保留已替换的坏图。

## A3：缩图影响包括接口

- resizeImpact 包括端口开口范围，影响文案明确接口会失效；缺省不允许有损缩图，取消零变更。
- 工作提案：确认有损操作后，把原 ports 完整放入明确的待修复记录，再设 ports=null；原图已有该记录时不能覆盖旧数据。可改为其他保真且可备份的方案，需说明理由。
- 有效接口不动，不把失效 col 自动夹取到边缘。撤销恢复原完整接口及其他内容；历史元信息不能被原地覆盖。
- 回归：20×12 / col10 缩为 8×12 未确认拒绝，取消无变更；确认后可 JSON 导出/重开，撤销还原；有效缩小、左上扩展仍正确。
