## R2 · 统一对象接触坐标与可观察样例（P1）

根因在 `js/world.js` 的 `FloorInstance.updateActiveObjects()`、`objectBox()`、`playerOverlap()`：对象框局部坐标，玩家/feet 世界坐标。不要仅给门补 offset；所有相关调用方都需采用一致坐标。

### 数据与接口约定

- 模板 `row/col/path.points` 保持局部格坐标；实例 `rx/ry` 保持局部像素；唯一 Player 的 `x/y/feet` 是世界像素。不能把 `origin` 累加写回模板或实例局部位置。
- 坐标转换继续由 World/FloorInstance 负责。接触 API 内把玩家转换到实例局部，或由统一 helper 返回世界对象框，再比较；方法名/注释明确坐标，所有调用方一起核对。渲染、固体碰撞、伤害、光环与恢复占位必须指向同一位置，不能各自重复转换。
- 不改变 `GameSession`、`FloorInstance`、模板只读与实例独立的所有权；不重建/传送玩家掩盖接缝或坐标问题。

### 实际行为

- **门**：正常从上/下/左/右碰到均触发；允许与现有物理解碰撞兼容的小接触容差，不依赖玩家穿进实心方块，也不远距离触发。触发后显示与实心判定一起移除，本局不恢复、事件不重复。
- **浮石**：落在顶面开始一次预警，采用已有默认 `warningSeconds=0.5`、`goneSeconds=1.6`。预警期间持续承重，不因持续站立反复重置计时；到时失去显示/碰撞。恢复前检查世界中玩家占位，仍占位则延后，不夹人。暂停冻结这些计时；不靠浏览器墙钟。
- **其余四类对象**：在有 x/y 偏移的上层核对弹簧弹跳、火球/地刺/齿轮接触伤害与光环权限。preview 继续非攻击预热，不提前触发门/浮石、伤害或攻击；进入 active 后才响应玩家。
- **新 B2 样例**：修正 `normal-2` 浮石与静态实心瓦片重叠等会遮蔽效果的位置；检查新样例的门/火球/弹簧路线，使代表行为可实际体验。只改必要新样例，保留原 12 图、迁移草稿与用户内容；使用 `sync_b2_levels.mjs` 重生成内嵌数据。无需禁止所有合法地块/对象叠加或重做编辑器。

- 遵循 B07：100 HP、无遗物、初始无活动光环、初始剩余 CD 20 秒、无作弊、无休整回复。满 20 个模拟秒后技能可用；施放后仍是持续 14 秒/从施放起 CD 20 秒，跨层保留、暂停冻结。

- 本次坐标/接触/标准规则改变影响通关有效性，升 `rulesVersion` 并更新 fingerprint，涵盖此次涉及的标准 profile 与实际参数。旧规则回执不得继续用于当前发布/抽选；旧内容/草稿保留，重新实际试玩认证，不清用户库、不伪造 passed。

## 集中验证

1. **有偏移的真实对象接触**：复用同一夹具在原点和至少一组不同宽高、x/y 非零的上层对照。按正常固定步跨线进入上层后，再用 Player 移动/解碰撞触发对象；不能只改 `floorIndex`、只调用对象 update，或把人塞进门内部就算通过。Node 测试可定位起步位置，但不生成认证。
2. **门/浮石结果**：四方向接触门只消失一次；浮石落地当步仍承重，约 0.5 秒后消失，约 1.6 秒后无占位才恢复；上层占位恢复安全；暂停至少一次验证计时不动。使用不被静态瓦片遮住的夹具，检查实际 `solidAt`，不只看 `state`。
3. **上层权限与伤害**：弹簧能弹；火球/地刺/齿轮在 active 上层能伤人；同一接触在 preview 不伤人；光环击中上层火球且不攻击 preview。重复模板两实例状态不串，跨层仍保留同一玩家。
4. **标准输入**：初始 K 失败，暂停不减 CD，冷却归零后实际页面 K 能施法，光环可见且能清火球；14/20 秒与跨层仍成立。旧规则回执不能发布/入候选，存储失败不改池，保留 B1-R1 回归。
5. **命令检查**：运行对应专项与一次 `node tools/test_all.mjs`，保留真实退出码；原有 4 条 floor09/floor11 诊断不靠改旧图/删断言消除。浏览器尝试一次主链路；无法启动则记录限制、继续可做工作，不伪造通过。
