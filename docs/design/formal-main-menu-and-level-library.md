# 正式主界面、种子文本与四档关卡目录（29号设计）

2026-11-09，**B4-R13已实施，29已验收通过**。用户人工正常，独立定向复验及旧源保留范围见[验收](../checks/review-B4R13-2026-11-09.md)。以下菜单/目录规则继续有效；30设置只新增历史最高分，参见[新设计](coins-archer-and-score.md)。只PC无新APK。

## 1. 主界面和导航

`index.html`成为实际的正式菜单/游戏壳，加载唯一正式控制器。上部是英文 **REVERSE ABYSS** 字标（HTML/CSS或仓库原生SVG即可，本轮不引入美术生成依赖）；中央只有“开始游戏”“退出游戏”，右下角独立设置图标。池统计、旧调试、导入/导出等不再堆在首页。菜单可用深色简洁布局，设置内再按卡片分组；不扩新的主题/背景特效系统。

legacy.html与short.html保留极小兼容跳转壳，**单向到index**，不加载旧控制器、没有另一套设置；index不能再重定向到short形成循环。作者现有legacy快捷方式会进入新菜单。编辑器/试玩“回游戏”、旧说明页等现存产品链接一律指index；试玩“回编辑器”的draftRef恢复保持28修复。编辑器从菜单同标签打开；“回游戏”在已有未保存保护后导航index，不误关闭整个游戏窗口。

“开始游戏”始终用当前选择的种子、启动时当前正式候选开新局，从0出生/F→1爬正式塔。固定0–40共41槽、36普通、10/30休息、20后F21/40胜利。首页不加继续、短塔调试、关卡选择按钮。游玩保留暂停/重开本塔/结果的必要控制；暂停与结果的“回大厅”若实际回程序菜单，应改名“返回主界面”，与0层游戏大厅区分。回主界面结束本局，下一次开始为新局；本局死亡/重试仍复用原不可变清单、不读取池重抽。

## 2. 设置范围

- 当前种子文本、输入/选择种子、按该种子重构、随机重构、保存种子、已保存文本列表。
- 普通池四档只读数量/来源说明，塔高只读“0–40层，固定”，没有输入/加减按钮。
- 导入关卡JSON及明确的导入结果/加入正式池动作。
- 打开编辑器、关闭设置。

设置只是正式菜单状态，不创建第二个Game/塔。重构更换或应用种子，基于当前候选准备待开局塔，不直接创建玩家、不给胜利/认证。每次新开局仍以同一个选定种子读取当时当前池；不能在点“开始”时又偷偷用Date.now随机一次。导入/本地发布/磁盘重新同步并刷新后池变化，开始按新池生成是用户接受的语义。

主菜单设置与已验触控布局不是同一个功能。复用现有触控布局，触屏时可放入设置子区或暂停入口；PC首页不多出“布局”按钮，不因新菜单重做触控/摇杆或打APK。输入框焦点时游戏快捷键不得触发，Esc先关闭设置；不保留M镜像/N塔高等旧菜单热键。

## 3. 种子只保存文本

用户明确不要塔快照：本地只保存规范化种子字符串，**不保存floors/模板/关卡版本快照/通过记录**。同种子＋同一候选集合/版本/规划算法可重建相同选择；池改变后塔可以不同，设置中用简短说明告知，不承诺跨池/跨玩法版本绝对复现。已开始本局自己的manifest仍是运行必需状态，不受本条禁止。

建议最小本地结构（实现选择，非用户逐字段指定）：

```json
{"version":1,"activeSeed":"RA-000001","savedSeeds":["RA-000001","RA-ABCDEF"]}
```

保存用新的专用key（如`ra_seed_texts_v1`），不覆盖作者库/旧偏好；本地列表可选择重构或移除该文本，同一规范文本去重。保存失败明确“未保存”，不把临时选择说成持久化成功；不生成SavedTower/DB快照系统。

沿用`RA-`加36进制短标签的显示格式，输入大小写可规范化，必须完整解析、校验范围，不能用parseInt部分成功/`>>>0`截断吞错误。实现选择有效数值1～0xFFFFFFFF，0/空/非法/超范围明确拒绝，避免当前Planner的`Number(seed)||1`把0静默变成另一座塔。随机重构保证新的有效种子不同于当前；数值变换集中一个SeedText工具，不能UI、存储、Planner各自解释。旧原型标签可以解析成数字，但不承诺复原旧镜像/旧高度的塔。

## 4. 导入关卡

复用PlatformFiles与ContentRepository的schema2导入/内容绑定解释，不再进入LevelPack旧custom/overrides存储。导入只存草稿并展示名称/难度/通过状态：有有效人工通过声明的普通图，作者再明确“加入关卡池”；未通过/改内容后失效的图给“打开编辑器试玩”，不自动passed/入池。取消文件选择、解析/哈希/读取错误、保存/发布失败都保留原稿/池/当前选定塔状态，显示真实错误。

有效通过判定沿用当前：内容可读取、normal、difficulty1–4、passed/支持profile、声明hash等于当前内容；技术规则只记录，不为新UI批量废旧作者通过。不恢复几何/净空/自动可达门槛。不导入旧asc/TXT为可玩图，不把固定场景加入普通池；旧数据只保真留档，必要转换仍从编辑器既有迁移走。

入口迁移还要核对原浏览器、原协议/来源下的草稿/发布记录仍可读。不能把换HTTP端口/浏览器导致的另一套存储误称已清空；file与HTTP本来可能分库，导入JSON是明确转移手段，不能自动合并未知旧库或假报已恢复。

## 5. levels目录和磁盘入池

用户确认**已通过JSON按难度放入目录，显式运行同步命令后打包为正式池来源**。文件夹不等于浏览器库；编辑器“导出JSON”仅下载/写所选文件，不会自动落进仓库或自动发布。作者放好文件并同步是显式内置发布动作，游戏启动不能扫描整个磁盘自动发布草稿。

```text
levels/
  normal/
    difficulty-1/        # difficulty=1，候选1–9层
    difficulty-2/        # difficulty=2，候选11–19层
    difficulty-3/        # difficulty=3，候选21–29层
    difficulty-4/        # difficulty=4，候选31–39层
  fixed/
    lobby.json
    rest.json
    boss.json
  fallback/
    test3.json           # 原规范fallback，不伪造通过
  archive/               # 只读历史/测试/迁移/作者旧备份，永不作为普通候选
  levels.js              # 工具生成的普通内置catalog，不手改
  README.md              # 作者如何放图、同步、导入/发布与目录对应
```

将现full40三个固定运行副本移到fixed，fallback_test3移到fallback/test3；内容/id/hash不变，更新sync_full40_levels路径和生成产物。原始`开发示例关卡/`原位只读保留，不修改裸x/地形/尺寸。现authored/b2/b4/v2/dev/demo等历史/回归资料集中到archive下独立子目录；现已有archive不重复套进自己。旧_template为旧格式也只读归档，不误充普通模板。

迁移前盘点**当前文件与实际引用**，按角色而非kind/名字猜测。建立oldPath/newPath/字节SHA-256映射，移动前后核对；同名不能覆盖。活动工具/测试夹具/构建/当前文档更新引用，历史验收记录不改写事实，通过迁移映射仍可找到文件。Windows操作先解析绝对路径确认在仓库，单一shell原生LiteralPath/安全文件API，不递归删除整个levels或跨shell拼删除。

作者最近导出的文件若不在项目内，不假装已迁移；明确给出放置位置，不能擅自搜索搬其它私人目录。不把作者原始无认证示例、开发fixture或历史verified=true图填入normal。空普通目录合法、仍用test3补位，不能为了有图把旧池重种回来。

### 同步工具的新契约

`node tools/sync_levels.mjs`只扫描normal/difficulty-1～4，使用共用LevelData编解码/`purpose:'load'`及通过声明判定；替换现根目录asc/verified旧契约。按JSON里的id/hash识别版本，不强制文件名=id；目录档位必须与JSON difficulty一致，不自动改字段/hash去迁就文件夹。

解析/内容hash/不支持类型/档位错误给精确文件路径并失败，保留上一份生成文件、不写半成品；可读取但无有效通过的草稿明确跳过并报“未入池，需试玩/发布”，不产生认证。相同id/hash的重复文件去重；同id不同hash按既有精确版本语义保留、不静默覆盖。所有引用、生成顺序稳定，不递归读archive/fixed/fallback。导出建议文件名可标明难度/标题以便查找，但仅改下载名称，不改JSON身份/hash，未选难度草稿仍可备份。

生成一个普通catalog（可保留兼容RA.LEVEL_DATA只读别名），带来源相对路径与规范data/ref。file://和HTTP均读该生成catalog，避免旧HTTP自动fetch另一份资料；改JSON后需同步再刷新，两种启动方式一致。

### 正式候选合并

普通候选=已同步的合格内置normal图＋浏览器显式published图。共用资格判定，按`levelId+contentHash`去重、稳定排序；相同版本优先标记builtin以免重复导入改变候选顺序。不同版本不擅自删，manifest记录精确引用/来源。候选source可扩`builtin|published`，fallback仍独立，不让archive/source/草稿进入。四档无放回每档最多9、本档不足test3、固定场景不进普通池保持。

建议`FormalPool.collect({builtinCatalog,repository})`或等价共享聚合，不给Editor/标题/Planner分别复制筛选规则。模板仍只读，Session克隆状态。内置来源不是重新开启25号旧池，不再次运行poolEpoch清空，不删除作者新发布。

## 6. 清理旧入口与逻辑

删除旧Canvas主菜单/设置及其专用Game/Tower启动链，包括镜像、可调塔高、旧关卡列表/选择、旧池合流、旧六图调试按钮、游戏首页导出当前图等旧产品入口。不能只隐藏按钮、仍后台创建旧RA.Game/扫描旧库或接受旧快捷键。

先列依赖，再移除无生产消费者的js/main.js、旧js/game.js、旧js/tower.js及UI旧菜单部分等；LevelPack若还有编辑器纯格式/命名功能，抽出/保留必要纯适配，不保留旧存储抽池执行链。旧playtest/standard/devplay控制器、Smoke旧菜单测试若只服务退役玩法，从生产加载与当前检查中退休；不为旧绿灯把镜像/塔高加回。保留真正共享的Player、Level、实体、绘制工具/迁移能力。

`Level.fromData`的关卡flipX/行反转与相关塔plan.flip执行路径取消；**Player朝向精灵图像翻转保留**。历史JSON未知/legacy镜像字段保真存档、不执行，不因清代码重算作者hash。固定塔高是**41个槽位**，不是锁死每张地图宽高，保留编辑器可变尺寸。

只移除旧浏览器库的自动读取者，不清`reverse_abyss.customLevels/overrides`、不清IndexedDB/草稿/认证/偏好。它们不再参与正式池；任何未来显式迁移另开需求，不能偷偷把旧数据认证入池。

同步所有HTML/loader/浏览器检查/工具依赖，`tests/browser.html`不能继续启动旧main。`build_android_www.mjs`必须改读新index壳（short已是跳转），只复制实际依赖/生成catalog/固定补位；不把旧菜单再打包。只重建必要www，不cap sync/构建APK。原安卓包0.3.2不变，PC设置打开editor；不假装www已包含PC编辑器。

## 7. 退出与状态

退出停止当前游戏/输入/帧循环，调用已存在的平台退出能力或尝试关闭当前游戏页；若浏览器不允许自动关闭，清楚显示“本局已结束，请关闭此标签页/窗口”，可回主界面。不能报已关闭但仍运行、杀浏览器进程/关其它标签，不能通过新开窗口绕限制。重入菜单只启一次循环，rAF/事件不叠加。

菜单/设置/playing/paused/result/exited应只有一个壳状态来源；保留当前Session时钟与生命周期，不另写游戏循环。设置异步导入/读池/生成应有请求序号，过期回包不能覆盖较新的种子/图；处理中避免双击开始多个Session。保存种子/导入失败不破坏成功的当前选择。

## 8. 验收与文档

可见屏幕从index、legacy、short均到新英文首页，仅两主按钮+右下设置；实际开始0/F→1、暂停/返回主界面/重试同塔。设置重构/保存和重载seed文本、导入已通过/未通过/取消/失败、打开editor返回、28未通关回原稿真实按钮，退出真实结果。检查无镜像/可调塔高/旧关卡列表/旧热键。

磁盘放入隔离的已通过schema2样例，按四档同步并真实读入新塔；未通过/档位错/坏hash不误入池或破坏旧生成物。证明档内最多9/精确ref去重/缺档fallback、同步后file与HTTP同源；迁移旧/新字节hash一致，归档不能被扫回。工程测试使用隔离fixture/证书，不写作者passed；作者实际通过图才能发布。

相同种子和相同候选稳定，相同种子但池更新允许变，重试本局不变。种子本地失败/取消不报成功。旧行为测试明确退休，基础物理/数据安全/25–28必要回归保留；不为了PASS数量重建旧菜单，不做全地图合规/寻路或强制再走41层。

README写新实际入口/操作/放图同步；PROJECT写来源/种子约定；STATUS写已做/未测；AGENTS写本卡边界，迁移映射与删除依赖清单进交付记录。代码/资源/目录均交由编码agent实施，本设计不是已运行新界面。

- `index.html` 为唯一正式壳：英文 REVERSE ABYSS、开始/退出、右下设置；`short/legacy/standard/devplay/tests/browser` 单向跳 index，不加载旧控制器。

- 退出停止 session/输入/循环并尝试 window.close；失败显示手动关闭提示并可回主界面。
