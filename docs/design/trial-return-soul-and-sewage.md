## B. 已确认玩法

### 灵魂

- 稳定type=`soul`。沿**方块外轮廓**移动，固定速度`V/2=170px/s`，V为正常地面最大移速340；不随玩家实际vx/空中上限/帧率变。攻击力/生命行为与火球一致：默认伤害20、光环命中一次消灭；不增加普通攻击/怪物血条系统。
- 用户确认放在**与方块上下左右相邻的空格**，沿外侧贴边绕行。空格指没有“方块轮廓来源”，其它怪物/污水池占据该格不算方块，不应否决或删掉对方。
- 第一次左键锁定位置并计算可移动方向，出现小箭头；随鼠标方向选择**合法方向**，第二次左键确认；右键取消整个本次放置，Esc可等价取消。无合法方向时红色提示，不提交对象/dirty/撤销。不能自动保存默认朝向跳过第二次确认。
- 灵魂不是作者绘制的固定path。门消失、浮石消失/恢复会改变几何，须按当前轮廓调整。用户确认：**附近无可继续贴附边缘时，按失去依附当刻的运动方向直线飞行；遇到下一方块后重新贴边**，不是停等、消失或回起点。原方向是当时朝向，不是最初放置朝向。
- 所有怪物彼此不碰撞、不改变灵魂路径；包含灵魂之间、污水池、火球/齿轮/锤头及其链/轨道、地刺。灵魂本身不阻挡玩家，但运动仍遵循方块轮廓；“不阻挡”不能误解成不再判定伤害或把方块当空气。

### 污水池

- 稳定type=`sewage_pool`，一格大小，可连续铺放；数据是对象而不是新增实心terrain tile。
- 固定接触伤害20、不可消灭、无实体阻挡。用户确认持续接触沿用现有受伤无敌时间，结束后可再扣20；不是每帧扣20，也不是永久只扣一次。
- 无扩散/液体模拟/游泳/减速。画成清楚的单格污水块即可，本轮不做正式贴图；同格其它怪物可共存，不推挤、不删掉对方、不成为灵魂轮廓。

显示约定：污水池在同格灵魂/其它怪物下方绘制；若原格有真实地形，使用可辨认底层轮廓的覆盖表现，避免盖掉石块后看起来像“池本身阻挡”。

## C. 灵魂轮廓与动态跟随

### 轮廓来源

使用独立的“方块几何”查询，不直接把`Player.blockedAt`或所有objects当作障碍：

- terrain tile1–4、tile5云板；云板对灵魂按完整格轮廓处理，玩家单向规则不变。
- 当前仍存在的门、未消失/预警中的浮石、弹簧板；按所属格轮廓。门broken后不计，浮石gone时不计、真正安全恢复后才计。弹簧属于方块机关，本批按整格轮廓处理是实现约定，不改其弹跳行为。
- 塔内只查询实际存活实例及实存石管石块，不能查询未加载模板；旧快照按保留地形/门浮石状态提供几何。独立试玩只有本图，无World/管道。
- 任何怪物本体/轨道/链条/污水池均排除，不能根据“看起来像方块”或对象大小判断。

普通怪物不迁移所属层。灵魂可按已有实存几何移动，但始终归原FloorInstance；正式进入下一层后原层snapshot清怪物，不能借贴边实现跨层追捕或在两层重复模拟。preview运动但不攻击/不受当前光环；其它生命周期同27。

### 运动语义与实现选择

以本体判定半径（默认同火球0.5格）作为贴边间距，保持在方块外侧；凸角用连续直角过渡，凹角走连通外露边，不斜穿方块或跨空隙瞬移。轮廓属于多个相接方块的并集，共享内边不走，孤立块可绕一圈，L形/门桥变化后走当前轮廓。

初始方向决定贴边手性；若同方向两侧都可依附，实现选择固定左侧优先，运行实例记录所跟随边/手性。此规则需编辑器预览和运行共用，不能运行时随机换边。失去支撑先在本体附近查连续边，无则进入直线搜寻；再遇到真实方块时按原手性优先选择可用切向方向重新附着，遇正面时也有确定转向。退化封闭几何须有限次处理、停在接触位置待更新，不能抖动/无限循环/穿越实心来伪造有路。

门/浮石状态改变后，同一步或最迟下一模拟步让相关魂重新查询。浮石在魂附近恢复时允许局部回贴/离开覆盖位置后重新附着，不把魂传送到远处；怪物不阻止浮石安全恢复（原安全恢复仍只考虑玩家）。可缓存当前轮廓/格边，但必须按**方块几何revision**失效；不能缓存一条固定路线导出成paths。每层共享几何更新，避免每个魂每帧扫描完整大地图。

灵魂只是读取这些方块状态，不代替玩家触发门消失、浮石承重或弹簧弹跳；污水池/其它怪物也不触发这些玩家机关交互。

作者可在放置后修改/删掉邻块：保存该魂，不自动删或改方向。运行时无初始贴附边则按已指定方向进入搜寻，不据此恢复几何/可达性发布门槛。放置时的合法方向交互限制与发布资格不同。

## D. 编辑器交互与数据

魂第一点击锁定格子，鼠标移动只改变箭头选择，不移动锚点；用鼠标向量与合法方向夹角选最近合法方向，指向非法方位时也只选合法项，相等/鼠标在中心时保持当前合法项避免抖动。第二击提交一份对象、一个撤销；取消/切工具恢复开始前内容/dirty/undo/redo，不影响已有元素，消耗按压防止顺带涂画。方向阶段不得保存/试玩半成品，提示先确认或取消；不用坐标/方向文本输入框。

污水池用既有笔刷连续铺单格，一笔一次撤销；同类同格幂等不无限叠加，不移除同格异类怪物。可区分同格叠放的绘制，不扩通用对象列表/参数卡。

为保证“怪物不改变魂路径”，所有怪物放置/移动/消灭不能暗中擦terrain或删门/浮石/其它对象。当前`placeObject`除flail外会清地形，普通绘制还可能移除同格对象；本卡做**怪物类型范围内**的最小分流，保留真实地形与异类对象，同类笔刷幂等。地形笔刷/作者明确擦整格是实际几何修改，可改变轮廓；门/浮石/弹簧等旧方块工具仍保留原替换规则。不重做通用编辑器。

继续schema2：

```json
{
  "id": "soul_1", "type": "soul", "col": 5, "row": 8,
  "params": {"radiusTiles": 0.5, "damage": 20, "initialDirection": 1},
  "pathId": null
}
```

`initialDirection`为整数枚举：0上、1右、2下、3左，必须显式保存，不静默补成“上”；UI只通过箭头生成，专用类型校验需要拒绝缺失/非整数/越界方向。缺数据草稿仍保真，不变成自动通过。半径/伤害沿火球注册范围，生命为现有alive/一次光环消灭语义，不新增HP字段。

```json
{
  "id": "sewage_1", "type": "sewage_pool", "col": 5, "row": 9,
  "params": {}, "pathId": null
}
```

池形状一格、伤害20在共享规则中固定，不使用terrain或伤害字段默认歧义。新类型本轮不引用paths，不允许误挂齿轮路径后静默忽略。魂当前朝向、hand、edgeRef、attached/seeking、rx/ry、几何revision、alive只在运行实例；初始方向参与内容hash，运行转弯不写模板/草稿。

新类型接入注册表/编解码/基础读取检查、画布图标/预览、JSON/草稿、裁空白/平移、试玩/显式发布与正式抽选。裁剪只对魂初始格/方向或污水格作一致偏移，不固化动态轨迹，不改方块真值；未知字段保留，规则由b4-8升b4-9但schema不变，不批量废旧作者通过。改作者内容才需重新试玩。
