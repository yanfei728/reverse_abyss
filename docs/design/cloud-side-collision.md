# 云板侧边穿墙：碰撞查询修复契约

日期：2026-11-08。状态：**B4-R2 PC 已实现（`eba80a6`，2026-11-08），待人工复测**。只修PC短塔穿墙；六图/F/休整/Boss流程保持，编辑器、APK和表现改进继续后置。证据见 [复验](../checks/review-B4R1-2026-11-08.md)、[探针](../checks/review-B4R1-2026-11-08-probes.mjs)，实施见 [18号卡](../tasks/18-cloud-side-collision.md)。

## 1. 已证实的缺口

17号卡已经使当前层生成的负行管壁参与Level._hitTiles；但FloorView.move仍只调用当前inst.level.move，blockedAt/standingOn也仅查inst。玩家头部进入上层start云板所在行时，脚底还没越过commitY，World.current仍是下层；上层已经显示，其旁边实心却不在查询里。于是角色能够从管内横移进上层泥土/石块，甚至整个人穿过，下一层仍preview。

复现覆盖4条连接×左右×两种横移时机，共16种，均出现超过1px的实心相交；持续贴边的8种可让整个20×36碰撞盒进入实心。探针仅在开始时把角色放到下端云板，之后用真实1/60固定步与方向/跳跃输入，没有中途改坐标、速度或floorIndex。它是接缝故障复现，不是整关通关。

另有同一适配链的坐标问题：第1普通层origin.y=-2000，而TS=45；originTileY用round(-2000/45)得到-44。start实际row22顶面是-1010；在它下面1px的世界点y=-1009，世界行floor(y/45)=-23，再减originTileY却得到local row21，blockedAt返回空气。move按原点减法查询，落脚容错却查询了别行。统一查询时必须消除这个不一致，不能把round换成floor就认为所有点都正确。

## 2. 必须保持的行为

- 云板仍是单向平台：下往上可穿，从上落下能站住，侧面不当墙；旁边真正的实心四向阻挡。
- 身体未整体通过上层start前，不提前入层、启用敌人攻击/伤害或超时；只露头、贴墙、横向离开开口不触发floorEntered。
- 正常穿管不传送、不重建Player，不重置跳跃次数/生命/halo/CD。大厅F例外、休整一次回血和Boss两阶段不改。
- 不加隐形边框，不改作者地形/端口/管道尺寸，不禁横向移动，不调速度/重力/跳跃来隐藏问题，不缩小碰撞盒。

## 3. 共享碰撞查询与坐标

保留现有Player积分、重力和按轴处理。修复发生在World与Level/FloorView适配处；不要求重写物理引擎或引入新框架。关键是**整个玩家碰撞盒**在每步实际运动中统一取得真实几何，而不是只按脚底所在层或current选一张网格。

建议以世界像素矩形作为适配边界（等价实现可以）：

```text
World.queryStaticContacts(worldRect) -> Contact[]
Contact = {
  rect:{x,y,w,h},                    // 精确世界像素，不是round后的格子边框
  kind:'solid'|'oneWay',
  source:'terrain'|'pipe',
  floorIndex:number,
  tileId:number
}
```

这不是新的可编辑地图格式。Contact只读派生自模板地形和现有LinkGeometry，不写回模板/本局存储。内部可用格查询或矩形查询，但返回的接触面必须在同一世界坐标中；材质为oneWay时不能被临时代理成solid。

查询包含当前层真实地形、管壁、已预加载上层起点附近真实地形，以及仍保留的上一层静态快照；仅查询当前运动AABB所需区域，不全塔永久启用。只读静态碰撞与active对象更新分开，上层参与地形碰撞不意味着伤害或计时提前启动。空白数组范围不是实心；重复几何去重，墙和云板只处理一次。

`move`的侧向/向上/向下检测、`standingOn`与落脚容错必须使用相同世界位置和接触面。可复用共享query或注入查询钩子；不能只给move补一个上层判断，仍让blockedAt查错行。Level供旧入口/隔离测试使用时保留合理本地查询回退，不恢复废弃关卡连接规则。

如果继续采用整数世界格，必须在World装配时明确保证爬塔区域原点和TS对齐，并验证所有楼层/管壁/快照；用TS倍数替换随意的-2000及其round近似是可选最小方案。另一方案是保留非整格原点，由精确世界矩形查询和对应落脚探针处理。实现方选择其一，写清坐标契约并实测；不能混用全局格和偏移后的局部格。

## 4. 侧墙与转角的接触处理

上穿过程中玩家的头和脚可能分属两个层：侧向检测必须包含上层那段身体；上层云板可穿，其左右支撑仍挡。保持接触面稳定，停止进入墙体方向的速度，不突然推到墙另一侧/跳到高处。处理同时按方向+跳跃、松跳、二段跳、上升转下落时的转角，不能等floorEntered以后才消除重叠。

上层静态地形不能伪装成动态solidEntity绕过分类：Level.move目前对动态实体顶头有进入1px以触发门/浮石的特殊处理，它不应自动作用于普通石块或管壁。碰撞来源/材质应能明确区分。已有机关触碰/预警/恢复规则不在本卡重设。

测试可沿用现有亚像素贴边约定，但不可扩大容差或允许重叠持续累积；本轮故障探针以两轴相交均>1px为失败，8种能达到整个身体相交，已排除单纯采样内缩。修复后应稳定贴墙且无法进入/穿出；不能仅用“没达到半个身位”作为通过条件。
