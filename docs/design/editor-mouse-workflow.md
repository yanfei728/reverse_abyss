# 编辑器鼠标工作流：端点标记、裁剪与直角齿轮路径

日期：2026-11-08。状态：**B4-R3 PC 已实现，鼠标画面待人工**。以本文件覆盖旧编辑器的端点坐标输入、拖框优先和至少两点路径规则。实施见 [19号卡](../tasks/19-editor-markers-and-gear-paths.md)，现状复现见 [编辑器审计](../checks/editor-gesture-scope-2026-11-08.json)。本轮PC，无APK；不增加怪物或开放Boss/大厅编辑。

## 1. 用户确认与边界

- 出口/起点和入口/终点不用手填坐标。点对应“标记”，鼠标带宽2格高1格边框，左键选云板，完成后自动显示坐标。
- 放下齿轮后继续左键加路径节点，图上实时连接，右键结束。单点即静止齿轮。
- 用户最新澄清：**不是曲线，只做水平/垂直折线，路径拐角只能90°，不做平滑。** “环形”是随节点首尾闭合的路线，不是圆心/半径的正圆。
- 本轮不新增敌人；保留现有火球/地刺/机关、齿轮参数、现代卡片深浅主题与固定场景只读。短塔及已通过B4-R2碰撞保持。

以下自动L形拐点、默认往返、手势撤销分组是本卡的实施选择，不是假称用户逐字段指定。若点击不同行不同列，预览中明确显示实际L路线，不能先画斜线后运行时另补拐角。

## 2. 坐标与裁剪的一份真值

模型`size/terrain/ports/objects/paths`是数据真值。col/row从0开始、相对于当前地图左上角；端点显示两格云板中左格的坐标。视图偏移/缩放/CSS尺寸/DPR仅用于屏幕转换，不写入模型或导出尺寸。齿轮节点仍为整数格坐标，运行/显示位置在该格中心。

现状已复现：test1裁前finish=(15,7)，裁后模型finish=(15,0)、尺寸20×16正确；但Editor.selection还留着(15,7)旧选区，applyCloudEndpoint优先用selection而非新坐标框，导致标记失败/指向旧位置。这是确定的一种原因，不声称覆盖用户当时所有操作。

所有改变地图几何/工作区的操作（裁剪、尺寸变更、撤销重做、打开/新建/导入）要清理或重建选区、鼠标悬停候选与端点标记状态，显示从新模型计算；不能把旧selection当作新地图坐标。正在画齿轮路径时先完成或取消手势再裁剪/切图，不能无提示丢节点。

裁剪继续是显式操作：预览旧/新尺寸、偏移及影响→确认→原子应用→单步可撤销。候选必须带beforeHash和workspaceToken（或等价revision），应用前确认仍是同一模型版本。取消/失败/旧候选不改数据、dirty、历史或发布池。

安全包络包括地形、端点/支撑/净空、所有已知对象实际占地与半径、路径所有线段和齿轮扫掠半径、已知活动装饰/兼容坐标。用`floor(min)`/`ceil(max)`保留完整格范围，不能只计节点格或对象中心。未知空间语义无法安全换算时拒绝自动裁剪并指出对象；已知历史归档/备注不是活动空间，不凭空平移其原始坐标。作者六图原件及运行副本不自动裁。

确认后，平移所有活动坐标及端口、齿轮和路径点；对象位置与首节点保持一致，刷新只读坐标/边框/路径显示，旧认证失效。普通导出仍如实编码当前模型，不在导出时偷偷裁图。

## 3. 端点标记交互

右侧保留两个角色卡片：“出口（本层起点start）”“入口（本层终点finish）”；各有“标记”“清除”和只读坐标。移除可编辑col/row输入及旧拖框优先分支。

画地形、端点标记、齿轮画路径等输入模式互斥；一次点击只由当前模式处理，不能标记时顺手画地块、画路径时又放第二只齿轮。手势状态不写进LevelData。

1. 点某个“标记”进入`mark-port`，记录role；清除旧通用selection的端点含义。
2. 鼠标在地图上移动，当前屏幕位置实时转换为当前模型格；宽2高1边框贴格显示。悬停一个恰好两格的云板段时，指向其中任一格均吸附到该段左格；其他情况以鼠标格为左锚点显示无效候选，不能误选另一个区域。
3. 候选须在地图内、确为完整两格云板；沿用端点角色、上下位置、两侧支撑和局部净空检查。合法绿色/无效红色并带简短原因。缺另一个角色可继续保存草稿，不把“另一端未画”当本次点击结构错误。
4. 左键合法候选，一次提交/一次撤销，替换该role旧标记，自动显示模型坐标后退出模式；无效点击零变更，不产生假撤销或清dirty。
5. 右键/Esc取消未完成的标记，不修改已有端点；只在画布活动模式内阻止右键菜单，不影响页面其他右键。

坐标是自动结果而不是第二个输入源。缩放、平移、裁剪后仍从模型推导；固定大厅/Boss/休整只读，不进入该模式。普通地图仍需start/finish，终局Boss单端口规则不改。

## 4. 齿轮绘制手势

选择现有“齿轮”工具后，第一次左键放下齿轮和首节点；自动进入`draw-gear-path`，不反复放多个齿轮。后续左键加节点；鼠标移动预览下一段，已放段/节点/首节点/当前齿轮位置始终可见。对象速度、半径、伤害用现有参数，不新增AI。

路径方式两个：**往返（默认pingpong）**与**闭合循环（loop）**。两者均为直角折线；一个节点无论当前方式都按静止处理。右键完成当前路线，不添加右键位置，终点为最后一次左键；完成后可继续放下一只齿轮。Esc取消本次未提交手势并恢复原工作。

点击策略：

- 目标与上个节点同一行/列，预览并添加一条水平/竖直段。
- 不同行不同列，自动补一个L拐点；默认先横后竖，若会立即反向重走上一段，则尝试先竖后横。实际将保存的转角在点击前就画出来，转角本身也存入points。
- 重复同点忽略，不生成零长段；同方向共线点可合并；不允许内部180°原路折返或斜段。两种L候选都不合法时保留工作并提示，用户继续加合适节点或撤销一步。往返运行在两个端点反向是既定运动方式，不是内部非法拐角。
- 闭合时也用上述可见直角连接回首点；必要拐点写入points，但不重复存第一点。至少两点的闭环需形成有效非退化直角环路，规范化后至少4个转角，连接处也是90°；不可两点直线来回伪称闭环。无法闭合时右键不丢工作，提示继续加点/撤销，或切回往返。单节点仍可直接完成为静止。

支持选择已有齿轮查看路线、用“重绘路线”从原齿轮位置重新画，保留旧路线直到新事务确认；至少提供“撤销本次最后一次点击”及取消。取消/失败不删旧路径。新建齿轮到右键结束作为一组撤销，自动L拐点属于同次点击。不是必须新增自由拖拽控制柄或复杂图形编辑器。

手势可用候选副本/事务实现：begin时保存workspaceToken+beforeHash，期间预览candidate；完成前验证未被异步打开/读取替换；确认才一起提交gear/path。保存/导出/试玩/裁剪/切图前明确要求先完成或取消，未完成手势也算未保存工作，不能离页无提示丢失。已验证的B1异步保存/读取保护保持。

## 5. 数据与共享模块

继续schemaVersion=2，沿用`objects[].pathId`和`paths[]`，不新增曲线/控制柄或一份编辑器专用路径真值：

```js
objects: [{id:'gear_1',type:'gear',col:3,row:5,pathId:'path_1',params:{/*既有参数*/}}],
paths: [{id:'path_1',mode:'pingpong',points:[{col:3,row:5}]}] // 单点静止

// 闭合矩形；最后一段回到首点由mode表达，不重复首点
paths: [{id:'path_2',mode:'loop',points:[
  {col:3,row:5},{col:8,row:5},{col:8,row:9},{col:3,row:9}
]}]
```

gear必须有有效pathId；新放置时即创建唯一的一点路径，所以不再要求用户填写id或手工补两点。路径首点与对象col/row相同；多只新齿轮各自有路径。导入的共享路径不静默拆/删，重绘其中一只时复制为独立新路径，不修改其他引用者。删对象/路线要检查引用，未知数据继续保真。

当前被齿轮引用的可运行路线：至少1个有效整数点；1点静止；2点以上每段水平或竖直、非零长；loop额外验证最后→首点和所有转角。旧斜线/损坏路径可导入保存草稿并显示原因，但不静默补L或丢点；试玩/发布前需作者明确重绘。未引用的历史信息不因UI变化被删除。

建议共享纯模块（名称可适配，但算法不能分别复制）：

```text
PathGeometry.appendOrthogonal(points,target) -> Result<{points,previewSegments}>
PathGeometry.closeOrthogonal(points) -> Result<{points}>
PathGeometry.validate(path) -> Issue[]
PathGeometry.compile(path) -> Result<{segments,totalTiles,bounds}>
PathGeometry.sample(compiled,distanceTiles) -> {col,row}
PathGeometry.sweptBounds(path,radiusTiles) -> Result<GridBounds>
Editor.beginPortMark(role) / previewPortAtPointer / commitPortMark
Editor.beginGearPath(cell) / appendGearNode / finishGearPath / cancelGesture
```

sample返回插值后的格坐标；World统一转局部/世界像素。运行仍沿节点格中心移动：单点固定，往返到端点反向，闭环最后段连续回首点；按实际长度与既有格/秒速度运动，不能末端瞬移、节点越多越快或在拐角自动抹圆。编辑器渲染、crop扫掠、接口净空检查及World用同一几何；扫掠/净空要检查整段和齿轮半径，不能只看节点。预热只动不攻击，暂停冻结，伤害/不可击败规则不改，不新增避障寻路。

新增模块按依赖顺序接入需要的HTML/loader/测试；核心不引用编辑器DOM/文件选择/Capacitor。按实际路径规则更新规则版本/指纹（例如path=orthogonal-v1），旧认证不伪造为有效；纯鼠标UI变更不单独制造玩法版本。
