# 设计决定与待定边界

更新：2026-10-30。本文件区分用户决定与设计提案，避免实现 agent 把讨论建议误当成已确认需求。

## A：用户已确认

| ID | 决定 | 来源 |
|---|---|---|
| A01 | 首版先短塔；完成后先做安卓游玩，再继续后续版本 | 本次讨论第 1 项答复 |
| A02 | 不能返回上一层，两层之间有梯板阻挡 | 本次讨论第 2 项答复 |
| A03 | 地图尺寸可变，只统一出入口规范 | 本次讨论第 3 项答复 |
| A04 | 下一层提前加载地形、素材、对象、敌人；到了上层才启用敌人攻击与超时计时 | 本次第二轮第 1 项答复 |
| A05 | 旧层保留地形，等再上一层才消失，不因镜头反复移入移出而销毁重建 | 本次第二轮第 1 项答复 |
| A06 | 技能持续 14 秒、施放起冷却 20 秒，其余接受前轮建议 | 本次第二轮第 2 项答复 |
| A07 | 开局技能可用；跨层保留光环/冷却；暂停冻结；普通击杀不消耗光环；命中 Boss 消耗本次召唤物 | “其它按你说的算”对应前轮技能表 |
| A08 | Boss 能量耗尽后不攻击，清除场上的伤害物，可受伤状态保持至命中 | 本次第二轮第 3 项答复 |

最终设想已明确且继续有效：JSON 取代 TXT；取消镜像；作者人工通关后发布；没有普通攻击；基础生命 100；通常敌伤 20；死亡回 0 层；固定特殊层；20/40 层 Boss 分别两/三个生命阶段；辅助模式可降低 Boss 阶段；龙/超时怪最多跨一次且不进特殊层；PC 编辑器、安卓游玩。完整功能不等于都进入首版。

A04 的工作解释：下一层敌人的移动/巡逻/外观计时提前运行，但不索敌、不生成攻击、不产生接触或机关伤害，超时为零。此解释采用对话中“提前运动但不提前攻击”的选项；实现时不得把下一层完全冻结。如果用户后续细化接触伤害边界，以最新指令更新。

## B：技术/范围提案，可用于实现，不冒充用户逐项批准

| ID | 工作提案 | 验证点 |
|---|---|---|
| B01 | v0.1 的样例内容为 3 普通层、1 休整、两阶段 Boss，静止火球/地刺/路径齿轮 | 短塔人工体验后调整，不开发完整敌人库 |
| B02 | 接口 v1 为宽 4 格，接口上下各 3 格保护带；底部入口、顶部出口的 X 位置可变 | 20×36px 玩家、45px 瓦片下的宽窄层拼接；T04 验证后冻结规格 |
| B03 | 脚底越过接缝且全身横向位于开口内后才提交入层；接口两侧封闭 | 头先过线、边缘擦过、反复起落不误判 |
| B04 | 下一层受保护，玩家光环也不能提前清除其敌人；保护区禁止伤害体进入 | 防隔层清场；不改变跨层光环保留规则 |
| B05 | 旧层是静态地形快照：保留退出时门/浮石的可见状态，不运行机关、敌人或掉落物 | 多次出镜/入镜无复活、无闪变 |
| B06 | 新模板 schemaVersion=2，数字瓦片网格，所有动态机关使用 objects；旧图保留原件迁移为草稿 | 不双写 asc，不把旧 verified=true 当有效认证 |
| B07 | 标准试玩：100 血、无遗物、技能剩余冷却 20 秒、无活动光环、无辅助作弊，敌人预热从 0 开始 | 比“每层满技能”更保守；不能保证低血入层或所有移动相位都可通 |
| B08 | v0.1 改图任何内容变化都使认证失效；规则版本与指纹也绑定认证 | 简化实现，避免影响玩法的改动漏失效 |
| B09 | 首版死亡重新开始同一塔清单；重构才改变模板组合；本局状态全重置 | 重温需求的基础；历史记录 UI 后置 |
| B10 | 暂停/失焦/后台冻结所有模拟，恢复前清按住输入；固定 1/60 秒模拟 | 防后台追时、粘键及不同入口计时分叉 |

任务允许在卡内验证 B 类方案；发现明显问题应给出具体复现和修订理由。A 类玩法不能自行更改。

## C：首轮调参建议

这些值不是用户确认值，统一由 config.js 管理；正式通关认证必须绑定实际采用的数值指纹。

| 参数 | 初始建议 |
|---|---|
| 光环伤害半径 | 角色中心起 1.5 格，圆形伤害区；视觉边界与判定一致 |
| 普通伤害、无敌时间 | 20 生命、1 秒；同一模拟步最多结算一次玩家受伤 |
| 休整回复 | 40 生命，最多到 100；每局每个休整实例仅一次 |
| 浮石踩踏预警 / 消失时间 | 0.5 秒 / 1.6 秒；恢复时避免夹住玩家 |
| 地刺预警 / 伸出 / 回收冷却 | 0.5 秒 / 0.8 秒 / 1 秒；实体底座阻挡，伸出的刺只判伤害 |
| 齿轮速度 | 2 格/秒，无停点；loop 闭环、pingpong 往返 |
| Boss 护盾攻击阶段 | 初始 12 秒，然后停攻暴露；具体弹速/攻击间隔由 T07 原型补表 |
| 模拟追帧上限 | 每次渲染最多 5 个模拟步；超出部分丢弃并记诊断，不积累到恢复后 |

## D：后续任务前需补齐的事项

- T01/T04：可变尺寸不代表无资源上限。容量上限要按内存、导入耗时与安卓小样测量设定，不能偷偷把所有地图改为固定大小。
- T07：Boss 激光/弹幕/火球的预警时长、范围、频率、可接触高度；从玩法原型记录具体调参结果。
- T07：越界坠落的正式处理未确认。封闭塔与防回落是正常路径；开发中越界报告诊断，不沿用“无伤回本层起点”作为正式规则。
- T10：Android 最低系统、实际测试设备、SDK/Capacitor 版本和安装步骤必须由安卓任务验证后锁定，本轮不编造。
- 后续：超时首次时间/重生间隔、完整遗物与敌人参数、四档难度参考、长局续玩和资源上传格式。

不需要为未来细节阻塞当前数据与保存任务。若某项未定规则成为当前卡的验收前提，再带具体方案讨论。
