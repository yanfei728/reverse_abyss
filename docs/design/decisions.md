最终设想已明确且继续有效：JSON 取代 TXT；取消镜像；作者人工通关后发布；没有普通攻击；基础生命 100；通常敌伤 20；死亡回 0 层；固定特殊层；20/40 层 Boss 分别两/三个生命阶段；辅助模式可降低 Boss 阶段；龙/超时怪最多跨一次且不进特殊层；PC 编辑器、安卓游玩。完整功能不等于都进入首版。

A04 的工作解释：下一层敌人的移动/巡逻/外观计时提前运行，但不索敌、不生成攻击、不产生接触或机关伤害，超时为零。此解释采用对话中“提前运动但不提前攻击”的选项；实现时不得把下一层完全冻结。如果用户后续细化接触伤害边界，以最新指令更新。

## C：首轮调参建议

这些值不是用户确认值，统一由 config.js 管理；正式通关认证必须绑定实际采用的数值指纹。

| 参数 | 初始建议 |
|---|---|
| 光环伤害半径 | 角色中心起 1.5 格，圆形伤害区；视觉边界与判定一致 |
| 普通伤害、无敌时间 | 20 生命、1 秒；同一模拟步最多结算一次玩家受伤 |
| 休整回复 | 40 生命，最多到 100；每局每个休整实例仅一次 |
| 浮石踩踏预警 / 消失时间 | 0.5 秒 / 1.6 秒；恢复时避免夹住玩家 |
| 地刺预警 / 伸出 / 回收冷却 | 0.5 秒 / 0.8 秒 / 1 秒；实体底座阻挡，伸出的刺只判伤害 |
| 齿轮速度 | 2 格/秒，无停点；loop 闭环、pingpong 往返 |
| Boss 护盾攻击阶段 | 初始 12 秒，然后停攻暴露；具体弹速/攻击间隔由 T07 原型补表 |
| 模拟追帧上限 | 每次渲染最多 5 个模拟步；超出部分丢弃并记诊断，不积累到恢复后 |

## D：后续任务前需补齐的事项

- T01/T04：可变尺寸不代表无资源上限。容量上限要按内存、导入耗时与安卓小样测量设定，不能偷偷把所有地图改为固定大小。
- T07：Boss 激光/弹幕/火球的预警时长、范围、频率、可接触高度；从玩法原型记录具体调参结果。
- B2：异常越界处理已由 A09 确认；封闭塔与防回落仍是正常路径。实现时记录越界诊断并走死亡回大厅/同塔重试，不沿用本层无伤重生。
