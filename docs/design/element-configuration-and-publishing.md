必要依赖包含 [B4-R10验收](../checks/review-B4R10-2026-11-09.md) 的N04延后确认方向与N05合法0伤害收尾，保留完整塔已验规则和手感。只PC，不做APK、美术音效/Boss技能/经济遗物。

## 作者操作

新增清晰的“选元素”工具，与现有地形框选区分。在画布点火球/地刺/齿轮，显示选中描边和该元素专属小卡片；点击空白取消选择，切换工具只改变编辑状态。选中本身不改图/hash/dirty/认证。重叠元素时可在卡片明确选择该格的具体元素，不能悄悄覆盖另一对象；未知元素保留并提示只读，固定场景仍只读。

放置仍沿用现有工具；火球/地刺落下默认值后可用“选元素”调整，齿轮右键完成路线后再调整参数。卡片只出现当前类型所需控件，不恢复全局对象列表、任意坐标和路径文本表单。卡片遮挡画布时鼠标事件不得透传；数字输入获得焦点时不能触发画笔、移动、Delete或快捷键。

| 元素 | 本轮可调 | 画布提示 |
|---|---|---|
| 火球 | radiusTiles、damage | 与实际objectBox一致的判定范围；图标保留现状 |
| 地刺 | warningSeconds、activeSeconds、cooldownSeconds、damage | 预警/伸出/回收的周期条和数值，不要求新增编辑器模拟器 |
| 齿轮 | speedTilesPerSecond、radiusTiles、damage | 已有路径与判定范围；路线类型/节点数可读，原创建流程保持 |

标签、单位、默认和范围取`EntityRegistry`/`C.OBJECT_PARAMS`；不能复制另一套常量。现注册表部分implemented注释/字段仍是历史状态，不能据此把已经运行的三类禁用。范围预览必须反映当前实际判定盒，不能画成另一种伤害算法；本轮不改变伤害形状或敌人行为。

参数输入先暂存在卡片并可在画布预览，标明“未应用”；点“应用”一次性提交本次参数变化，点“取消”/Esc只丢本次参数预览，不删除原对象或其已完成路线。先前放置是独立操作。存在未应用输入时，切图/换元素/保存/试玩/发布须让作者先应用或取消，不能悄悄提交或丢弃；用卡片内提示即可，不新建全局审批流程。

空字符串、非有限值、越界无效，错误就地提示且原数据不动。步进精度不能缩窄注册表允许的已有数值，不静默取整/夹值。0伤害有效；地刺0预警/0冷却有效，运行时必须尊重。应用后还选中原元素，不重建其id/pathId。无变化应用是no-op，不造撤销/dirty/hash变化。

## 数据与接口

继续schema2，`objects[{id,type,col,row,params,pathId}]`、`paths`、模板hash与认证结构不变。选择/卡片输入/预览属于Editor临时状态，不写JSON。原未知参数、字段、extensions、路径引用与其他对象完整保留；不因为只显示3类控件就重建/精简整个对象。

建议内部接口（可等价命名）：

```text
Editor.beginElementParams(objectId) -> 临时副本{objectId,beforeHash,paramsDraft}
EditorModel.patchObjectParams(objectId, changedParams)
  -> Result<{changed:boolean, objectId}>
Editor.applyElementParams() / cancelElementParams()
```

模型参数更新先对候选副本检查类型/范围/对象身份，再原子提交；仅允许本卡当前类型注册键，合并其余字段。失败零修改；成功实际变化一条撤销/重做，取消零残留。参数更新不得清地形、改位置/端点/路径或触发自动裁剪。现`updateObject`还会清对象脚下terrain且在检查前修改字段，不能直接把它当无副作用的参数事务；可最小修正该API或增加窄参数补丁接口。

真正内容变化会重新计算hash，旧通过与新内容不匹配、需要重新试玩；保留历史记录，不能伪造passed或借规则版本批量作废旧作者图。草稿revision/异步请求令牌保护沿用，卡片应用期间草稿切换不得改到另一图。主题/选中/预览不算内容变化。

N05：火球/地刺/齿轮的damage只在字段缺失时从注册表取默认，显式0必须传到共用伤害处理（不扣血、不产生受伤事件/无敌时间）。非法值沿现有只读检查报错，不默认为20。试玩与正式共用FloorInstance行为，不写两份参数解释。

N04：按世界坐标方向修正pending的确认/取消。已合法上穿后，在顶面上方重新进入开口时确认；也可凭该次合法上穿记录及身体已完全落于上层自身表面确认侧移落脚，不能要求角色永远居中。真正回落到顶面下方取消，切层/F/重试清理。审查`standingOnOwn`补偿的资格，不能无上穿依据就因任意站位激活下一层。仅修必要分支，保留已验有效碰撞体、最多3实例/实存连接/单向云板；不重写物理。

## 试玩、发布与正式选择

本轮是核对和修具体断点，不另建发布系统。保存草稿/JSON备份不要求先通过；试玩仍只有当前图，普通移动/HP/技能/伤害；人工完成后回原草稿，显式发布。参数/难度变化须重新试玩，未应用参数不能带入认证。应用失败、保存失败、revision冲突、试玩失败/取消均不能改发布池或假报成功。

正式difficulty1–4仍对应1–9/11–19/21–29/31–39，每档无放回最多9；本档缺口test3。新发布只影响新建塔，当局不可变清单和死亡重试不变，不能实时替换当前层。新开塔能从已发布版本读取完整objects/params/paths。利用现有`RA.short.state.manifest`等只读信息核对id/hash/source/requiredDifficulty，按需输出来源快照；不强制新增调试面板。

工程验证放在隔离存储/临时浏览器fixture中，不清作者库、不把测试证书写进作者草稿。真实“作者试玩→发布”由用户执行；代理不得代打用户图或补写passed。正式池图多于9张时新图可能未抽中，不应改概率/跨档规则只为了演示抽到；可用隔离少量候选验证分桶，再给作者如实说明本局结果。

## 人工验收
