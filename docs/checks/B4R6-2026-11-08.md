# B4-R6 交付记录：试玩控制/基础交互一致性

日期：2026-11-08。依据 [22 号卡](../tasks/22-trial-gameplay-parity.md)、[一致性设计](../design/trial-gameplay-parity.md)。只 PC；保留已人工正常的单图 start/finish、齿轮、标记、裁剪、B4-R2 碰撞。

## 完成

- `TrialSession.update(realDt)` 改为累计固定步：
  - `STEP=1/60`、`MAX_FRAME=0.25`、最多 5 步；`dt` 非有限或 <=0 不模拟。
  - 角色、对象、HP/CD/光环全部使用同一个 STEP，不再每 RAF 直接推进一次 Player。
- 基础对象统一走 `FloorInstance.updateActiveObjects(STEP,this)`：
  - 门触碰 broken；浮石预警/恢复；弹簧；地刺周期伤害；齿轮路径/接触伤害；火球接触伤害。
  - 删除试玩自写 `_objects` 简化伤害表。
- 光环：`_applyHalo` 用共享 tuning 半径清除火球；不杀齿轮/地刺；`fireballDestroyed` 事件。
- 输入：
  - `trial.js` 改为 `RA.ActionInput` 来源合并；D/→、Space/W/↑ 分别释放，不再松一个砍断另一个。
  - K 边沿、P/Esc、R、暂停/继续/重开按钮接同一控制；blur/hidden 清输入并暂停。
- HUD：补生命条 + HP 数值、K 开局 CD20/就绪/活动三态；画布绘制 14 秒光环范围。
- 规则升级 **`b4-5`**，`trial=single-map-v2`；旧 b4-4 认证只保留历史，不自动续用。
- 单图 start 出生、完整上穿 finish 通过一次并冻结保持不变。
