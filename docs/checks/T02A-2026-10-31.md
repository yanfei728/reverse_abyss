## 2. 模型契约落地

| 任务卡建议 | 实际实现 |
|---|---|
| `fromData` / `toData` | `EditorModel.fromData()` 走共用 `LevelData.decode`（深复制、校验自报 hash）；`toData()` 返回深复制快照。另提供 `fromJSON`（v2 文本）与 `fromLegacy`（只走 LegacyImport）。 |
| `getTile` / `setTile` | 只改 `data.terrain.tiles`；字符画笔通过 `getChar` / `applyChar` 适配，**没有第二份 cells 真值**（`model.cells === undefined` 有断言）。 |
| `placeObject` | 从 `EntityRegistry` 生成唯一 id（`spring_1`…）与必填默认参数；`S/x/y` 画笔映射到 spring / crumble_door / blink_platform。 |
| `resize` / `translate` | `resizeImpact()` 先统计会丢的地形格、对象、路径、出生点、装饰；`resize()` 未确认返回 `NEEDS_CONFIRM` 且零变更，确认后整次提交；`grow(l,r,t,b)` 把地形、对象、路线点、出生点、装饰、接口 col 一起平移，**不改写 extensions.legacy 里的历史坐标**。 |
| `undo/redo` | 快照整份 LevelData；最多 100 步 / 32 MiB（按真实 JSON UTF-8 字节估算，超出淘汰最旧）；一笔拖动只记一次。撤销不恢复旧认证。 |
| 元信息 | `title` 与 `id` 分离：改名不改 id，新建生成稳定合法 id；难度 1~4、背景 `skyN` 是显式控件；`extensions` / 路径 / 装饰 / 未知字段原样保留。 |
| 认证失效 | 任何内容编辑调用 `invalidate()`：`contentHash` 与 `certification` 立即清空；导入时合法认证保留显示直到第一次编辑。 |
| 校验 | 检查面板直接调用 `LevelData.validate({purpose:'draft'})`，显示 `[CODE] path message`；`errors` 阻止导出，warnings/notes 照常展示（含迁移警告、`ports=null`、旧 G 位置）。 |
| 导入 | 「打开 JSON…」只接受 v2（未来 schema 拒绝）；「导入旧图…」只走 LegacyImport，保留警告与待修复引用；失败不替换当前图。内置关卡下拉框打开只读迁移副本。 |
| 导出 | 只导出 JSON（`LevelCodec.encode`），显示 code/path/message；下载只报“已发起导出”，不清 dirty、不写 `levels/`；旧 TXT 导出/「保存到游戏」/自动改池整条移除。 |
| 试玩/发布 | 按钮禁用并说明等 T03/T04/T06；不会把新格式转成旧 TXT 偷跑旧试玩。 |

界面上的出口 `G` 不再是画笔：旧 G 只在画布上以虚线“G旧”显示（来自 `extensions.legacy.exit`），新出口是 `ports`，完整端口工具留 T04。未知对象用紫色 `?` 占位，已注册但无旧字符的机关（火球/地刺/齿轮）用蓝灰占位显示类型缩写，两者都不会从画面或文件里消失。

## 4. 真实浏览器验收

脚本：[tools/browser_t02a.mjs](../../tools/browser_t02a.mjs)。它启动本机 Chrome `--headless=new`，用 DevTools 协议：

1. 打开 `editor.html`（`file://`），等 `RA_EDITOR_READY`；
2. 通过页面自己的 `openJSONText()` 载入演示 JSON（与文件选择后的处理同一条路径）；
3. `Input.dispatchMouseEvent` 在画布上真实按下/拖动/松开，画出单格与连续一段；
4. 点击页面「撤销」「重做」按钮，核对模型；
5. 真实滚轮事件缩放、右键拖动平移；
6. 点击「导出 JSON」，用 `Browser.setDownloadBehavior` 接收真实下载文件，解析并核对未知字段/路线；
7. 把下载文件重新交给页面 `openJSONText()` 打开，核对内容仍在；截图三张。
