## 2. A1：机关画笔同格幂等

实现（[js/editor.js](../../js/editor.js)）：

- 画笔的 S / x / y 分支改走 `brushObject(type,col,row)`：同格已有**同类型**对象时直接返回“无变化”，保留原 id、参数和未知字段；没有同类才创建。
- 同格已有**其他类型**对象时，明确覆盖（移除旧对象后创建新对象），整次操作仍由一次拖动的 undo 快照撤销。
- 矩形、油漆桶、多格笔刷都经过 `applyChar`，因此同样每格最多一个同类对象；不会靠“删掉再重建”制造只有一个的假象。
- 显式 `placeObject()` 仍是“创建一个对象记录”的 API（未来对象工具可能允许叠放）；普通界面画笔不调用它来堆叠。

验证：

| 场景 | 结果 |
|---|---|
| 同格 `applyChar(…,'S')` 60 次 | 1 个 spring（修复前 60 个），id / 自定义参数 / 未知字段不变 |
| 同格 x / y 各 30 次 | 各 1 个 crumble_door / blink_platform |
| 3×3 区域填 S 两次、再油漆桶换 x | 9 个对象，每格 1 个 |
| 已放 390 个对象后同格重复 60 次 | 仍是 390，不消耗配额 |
| UI 按住 S 60 帧（约 1 秒） | 1 个对象，1 步撤销，撤销后清空 |
| 真实浏览器按住 S 1.2 秒 | 同格 1 个 spring |

复现脚本对照：`objectCount` 60 → 1。

## 3. A2：结构错误导入零替换

实现：

- `EditorModel.fromData / fromJSON / fromLegacy` 在 `decode` 之后统一走 `checkCandidate()`：`validate({purpose:'draft'})` 有 error 就返回 Result 失败（带 code/path/issues），**不构造可提交模型**；warning 级草稿（ports=null、未知对象、断路径）仍可打开。
- `openJSONText / importLegacyText` 捕获候选构造异常；`replaceModel()` 先保存旧模型、撤销/重做栈、字节计数、dirty 与视角，UI 渲染若仍失败则完整回滚，绝不留下半替换状态。
- 检查面板的接口说明改为容错：缺 `ports.entry/exit`、col 不是整数时不再读嵌套字段，由共享校验报告 `INVALID_PORT`，面板不抛异常；导出仍明确失败，不静默补成合格接口。

验证（模型 + UI）：

| 输入 | 结果 |
|---|---|
| 缺 entry / 缺 exit / col 不是整数 / col 越界 | 导入返回 false，无异常，旧 id/title/数据/历史/dirty/视角全部不变，提示含 `INVALID_PORT` 与 `/ports` |
| size 与地形不一致 / 非法地块 / 缺 terrain / 路径点损坏 / 装饰不是数组 | 导入失败、无异常、旧图与历史保留 |
| ports=null + 未知对象 + 断引用 | 正常打开、可编辑、可导出 |
| 直接塞入缺 entry 的模型 | 检查面板不抛异常，显示 INVALID_PORT；导出失败 |

复现脚本对照：`returned` null → false，`exception` TypeError → null，`oldWorkPreserved` false → true，`currentId` 不再变成 `bad_ports`。

## 4. A3：缩图影响包含接口，确认后保真备份

实现：

- 新增 `portsInvalidAt(cols)`：按 `PORT.openingCols`（4 格）检查 entry/exit 的开口是否放得下；`resizeImpact()` 增加 `ports` 计数并计入 `total`。
- 未确认的有损缩图仍返回 `NEEDS_CONFIRM` 且零变更；UI 确认文案明确列出“接口 N 个(会完整存进 extensions.retiredPorts,再把 ports 置空)”。
- 确认有损缩图时，先检查 `extensions.retiredPorts` 可写（必须是数组或不存在），否则整次拒绝；然后把**原始 ports 完整**追加到 `extensions.retiredPorts`，记录 `source/profile/ports/before:{cols,rows}`，最后 `ports=null`。
- 不夹取 col、不伪造接口；有效缩小/扩展保持原接口 col（扩展时按统一平移规则改 col）。
- 撤销恢复原 ports 与其它内容，退役记录随快照一起消失。

`extensions.retiredPorts` 示例：

```json
{
  "retiredPorts": [{
    "source": "editor-resize",
    "profile": "vertical-v1",
    "ports": { "profile": "vertical-v1", "entry": { "col": 10 }, "exit": { "col": 10 } },
    "before": { "cols": 20, "rows": 12 }
  }]
}
```

验证：

| 场景 | 结果 |
|---|---|
| 20×12、接口 col=10，`resizeImpact(8,12)` | ports=2，total=2 |
| 未确认缩图 | `NEEDS_CONFIRM`，数据零变更 |
| 确认缩图 | 成功，ports=null，retiredPorts 1 条且原 col=10、before 20×12 |
| 缩图后导出/重开 | 成功，退役记录保留 |
| 有效缩小（col=2/3） | 接口不动、无退役记录 |
| 向左/上扩展 | 接口 col 一起平移且有效 |
| 已有 retiredPorts | 追加，不覆盖旧记录 |
| retiredPorts 不是数组 | 整次拒绝，不覆盖旧数据 |
| UI 取消 / 确认 / 撤销 | 取消零变更；确认后可导出；撤销还原接口并删除退役记录 |
| 真实浏览器 | 取消零变更、确认后 ports=null + 退役记录、撤销还原 |

复现脚本对照：`impact.ports` 0 → 2，`resizeOk` true → false（需确认），`remainingPorts` 不再被静默留下为无效接口。
