## 1. 云板端点与连续性

- 新普通层使用 `ports.profile = cloud-pipe-v2`，只有 `start`（出口/本层起点）与 `finish`（入口/本层终点）两个 `col+row` 锚点，各是连续 2×1 云板（tileId=5）。宽度、高度不重复存储；管内宽 2/高 3、墙厚 1、两端顶面差 4 格集中在 `js/config.js`。
- `js/cloud-pipe.js` 提供共享验证、起点 pose、下一层 origin、石管 `LinkGeometry`；`LevelData`、`World`、编辑器、标准试玩共用。
- `World` 用 `finish.row/start.row` 计算楼层原点；石管两侧墙是运行时只读几何（碰撞 + 渲染），不写回模板；端点云板仍只有 `terrain.tiles` 一份真值。
- 角色从 `start` 云板生成（`spawn:null` 合法），脚底越过**上层 start 顶面**且身体在 2 格开口内才提交一次 `floorEntered`；保留同一 Player、生命/光环/CD、预热、快照、防回落、暂停。
- 0→1 为 `lobby-direct`（无管壁），其余连接为 `stone-pipe`；Boss 最后无后续管。
- 管内实际渲染石墙/净空；截图见 [短塔](b4-short-960x540.png)。

## 3. 普通编辑器

- 移除旧 P/G 操作入口（旧字段仍保真）；新增“选段”工具：屏幕拖 2×1 云板后，在右侧点“标记起点/终点”；也接受坐标输入。1×1/3×1/纵向/非云板/部分云板会拒绝。
- 左侧按 EntityRegistry 列出所有已注册对象，无旧 letter 的火球/地刺/齿轮也直接可点图；弹簧/门/浮石保留。未知对象只显示占位，不能运行/发布。
- 尺寸：输入宽高后点“应用尺寸”，模型/导出/草稿同一尺寸；自动扩展默认关闭，显式启用才越界扩图；视图缩放/平移/主题不写模型。
- 裁剪：先计算内容包围盒（地形/对象/路径/端点/出生/装饰），预览原→新尺寸和偏移，确认后整步提交，端点行列同步平移；云板端点/净空被破坏时拒绝候选；取消/失败零变更，撤销完整恢复。作者三图运行副本不自动裁。
- 固定 Boss/大厅/休整只读：横幅提示、主编辑按钮禁用、画布/端点 handler 也拦截；可查看/导出原数据，不转普通图。
- 现代扁平工作台：三栏卡片布局、中性色 + 单蓝强调、顶栏主操作、右侧尺寸/端点/对象卡片；浏览器本地主题偏好，浅/深色覆盖 UI 与 canvas 网格/边界，不写入关卡/认证。
- B1 异步保存/读取/试玩令牌与冲突保护未改；IndexedDB/正式池不清。
