## 2. A3-C · 缩图容量预检与原子提交

实现（js/editor.js）：

- `resizeCandidate(cols, rows, opts)` 在 `EditorModel.fromTrusted(this.toData())` 的**完整副本**上：改尺寸 → 追加 `extensions.retiredPorts` → 清派生字段 → 调用共享 `encode`。
- 只有候选能导出才返回 `{model, impact, retired}`；容量/结构失败返回原错误码（优先取 issue 的 `LIMIT_EXCEEDED`），原模型完全不动。
- `resize()` 只在候选成功时替换 `data`；`changeSize()` 先预演，失败不 `pushUndo`、不碰 redo/dirty/视角。
- 不截断作者 extensions、不扩大上限、不跳过校验。

## 3. 浏览器草稿（T02B）

新增 [js/content-repository.js](../../js/content-repository.js)：

- `ContentRepository.create()`：有 IndexedDB 用 `ra_drafts/drafts`；没有时内存兜底并明确 `persistent:false`（刷新会丢），UI 显示存储类型。
- `saveDraft(draftId, data, expectedRevision)` 先按 draft 用途 `validate`，再 `encode` 成规范 JSON；写入的是**发起保存时的快照**。`expectedRevision` 与库内 revision 不一致返回 `CONFLICT`，不覆盖另一窗口。
- `listDrafts()` / `loadDraft(id)` / `deleteDraft(id, expectedRevision)`；写入/读取失败返回 `STORAGE_FAILED`，不清 dirty。
- 编辑器：`draft-select` + 保存/打开/刷新；`draftRevision`、`draftId`、状态提示；新建或导入后不沿用旧 draftId。保存成功后比较"快照 hash"与"当前 hash"：不同则仍标未保存，状态明确写"保存期间又有改动"。
- 草稿按 id 保存，revision 递增；打开草稿会按 play 结构再校验，坏草稿不替换当前图。

Node 回归（`test_editor.mjs`）：

- 保存 revision 1 → 2、列表可查、新编辑器恢复完整内容；
- 两个编辑器同一 revision，先保存者赢，后保存者 CONFLICT 且不覆盖；
- 存储失败返回 false、dirty/revision 保留、旧记录 hash 不变；
- 保存期间继续编辑：落盘的是发起时快照，成功后 dirty 仍为 true；
- 含未知对象/路线/extensions 的草稿保存再读回 canonical 相等。

真实浏览器（`tools/browser_b1.mjs`）：编辑开发样例 A → 点「保存草稿」→ 刷新页面 → IndexedDB 列表仍能找到 → 点「打开草稿」恢复地形/接口/出生点/extensions。

## 4. 共用 GameSession 与连续楼层（T03/T04 的 B1 部分）

新增 [js/world.js](../../js/world.js)、[js/session.js](../../js/session.js)：

- `GameSession.create({floors})` 对每一层跑 `validate(play)`，有 error 拒绝启动；`Player` 只创建一个，跨层只切换 `level` 适配层，不 reset。
- 固定步长 `1/60`，`update(realDt)` 最多 5 步/帧、最多 0.25s；`pause()` 后不推进并清空累加器，`resume()` 不追算后台时间。
- `World` 预计算相邻层原点：`(cur.exit.col - next.entry.col) * TS` 对齐开口，纵向按下一层高度叠放；整体平移到 x≥0。
- 生命周期：进入第 n+1 层时，第 n 层变 `snapshot`（只保留地形），第 n+2 层创建为 `preview`；进入 n+1 时才释放 n−1。四层诊断夹具验证 n−1/n/n+1。
- preview 只累计 `previewTime` 并跑非攻击环境运动（路径对象占位），`activeTime` 保持 0；snapshot 不再模拟，`activeTime` 冻结。
- 过界：玩家脚底从下往上越过当前层顶边、且身体完全在 4 格开口内才提交一次；`floorEntered` 事件一次。底边作为单向梯板，防止从入口回落。
- 顶层无下一层时开口不再放行；左右外墙、顶边非开口处按实心处理；边缘不会穿出地图。
- 页面（js/devplay.js）只做 canvas/键盘/暂停遮罩/镜头跟随/背景；`P`/`Esc` 暂停，`R` 重开，页面切后台自动暂停，不自动恢复。

Node 回归（`test_world_session.mjs` 41 项）：两层启动、预热 activeTime=0、一次越线一事件、速度/位置连续、底边防回落、四层释放时序、快照冻结、原点对齐、暂停不追算、样例同步与不在正式池。

## 9. 手动复验（用户本地）

1. 双击 `editor.html`，点「打开 JSON…」选 `levels/dev/floor-a.json`；改一笔，点「保存草稿」。
2. 刷新页面；在「浏览器草稿」下拉里选 `开发样例 A(下层)`，点「打开草稿」；确认改动画和保存前一致。
3. 点「▶ 开发试玩(两层)」；用 `A/D` 移动、`Space` 二段跳穿过顶部虚线开口；HUD 变成 `2/2` 层。
4. 按 `P` 暂停，等待几秒再点「继续」；HUD 的模拟时间不应跳一大段。
5. 回编辑器或直接打开 `devplay.html`，确认内置样例 A+B 也能玩。
