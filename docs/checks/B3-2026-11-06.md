## 1. 交付内容

- **复用核心**：短塔仍由同一 `GameSession/World/TowerPlanner` 驱动；平台层只做输入、文件、生命周期、布局，不复制物理/战斗。
- **语义输入**：`js/platform/action-input.js` 支持多来源 held、左右抵消、一次性 press；键盘与触控都进入同一 Session。
- **触控**：`short.html` 左下左右、右下跳跃/技能；`pointerId` 独立来源，滑出/抬起/cancel/失焦/后台释放；长按不重复施法；暂停/菜单/设置不依赖键盘。
- **布局**：`js/platform/control-layout.js` schemaVersion 1，归一化坐标/大小，安全区域容器；设置可拖动、调大小、保存、重载恢复、恢复默认；存储失败保留旧值并提示。
- **生命周期**：`js/platform/lifecycle.js` 后台清输入→暂停、前台保持暂停、返回面板→暂停→退出；Capacitor App 事件或 Web visibility 适配；不重建 Player/Session、不补现实时间。
- **JSON**：
  - `js/platform/files.js` 系统选择/Web 下载/Android Filesystem Documents + Share；区分 download-started、written、share-opened。
  - `ContentRepository.importLevel()`：decode/play 校验/hash/保存不可自动发布草稿；认证仅在 profile/hash/rules 匹配时 eligible；`publishImported()` 需用户明确加入，来源标 `imported-declaration`，不生成 local-playtest。
  - 页面有「导入关卡 JSON」「导出当前关卡 JSON」「把导入内容加入正式池」。
- **离线包**：`tools/build_android_www.mjs` 只复制 short 页面引用的脚本、B2 模板、levels.js 和 assets；不含编辑器/测试/文档/旧原型。
- **Capacitor**：`capacitor.config.json`、`android/` 工程、`js/platform/capacitor-bridge-src.js`（esbuild 本地 bundle），锁定 Capacitor 7.6.10。Android manifest `sensorLandscape`，target/compile 35。
