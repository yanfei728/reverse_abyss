## 人工步骤

1. 编辑器打开一张合法普通云板图，点“试玩验证”。
2. 应只在当前图 start 出生，无入口/出口支撑或额外石管；HUD 不显示 1/3 层。
3. 从 start 跳到 finish 上方完整穿出；确认立即显示“试玩验证通过”，时间/对象不再动。
4. 回编辑器确认认证已保存；点击发布才进入本地正式池。
5. 重开/暂停/死亡分别确认失败/重试，不进入短塔大厅。
