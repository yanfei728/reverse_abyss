## 1. 失败复现

原独立探针的历史结果保留：4 条连接 × 左右 × 起跳即横移/第 17 帧横移，共 **16 种**；全部出现超过 1px 的上层侧实心相交，其中 8 种可整身 20×36 进入墙内。旧 JSON [历史故障证据](review-B4R1-2026-11-08-probes.json) 不被本次修复覆盖。

## 2. 修复

### 统一世界静态查询
- `FloorInstance.otherStaticAt()` 把当前层局部格换算到 **世界像素**，再查询当前/预热/前一层仍存活实例的真实 terrain 1～4；上层 preview 起点侧支撑因此进入碰撞。
- `Level._hitTiles` 支持负行/数组外；`FloorView.move/blockedAt/standingOn` 继续经同一 `solidEntityAt` 适配器。
- 只查询运动 AABB 附近，不永久启用全塔；只读静态几何，不提前运行 preview 对象攻击/activeTime。
- 云板仍单向：上层 start 云板不因侧墙查询变 solid；石墙四向。

### 坐标一致性
- 大厅→第1层独立布局原点由不整的 `-2000` 改为 **`-2025 = -45×TS`**，所有塔原点为 TS 整数倍。
- `originTileY/floor` 与 `blockedAt` 不再因 round(-2000/45) 落到相邻行；原云板顶面 +1px 的映射断言通过。

### 转角
- 上穿时头在上层/脚在下层，上层左右实心参与整个碰撞盒；侧向移动被墙夹住，不累积、不推向墙外、不突然抬高。
- 普通地形/管壁不使用动态实体“顶头进入1px”处理；现有机关规则未改。

### 边界
- 四条连接仍 2×3 净空、两侧 6 块 tileId=4 石块；R1 外观保留。
- 基础重力/跳跃/玩家尺寸未调；地形/端口未改；正常换层不传送、不重建 Player。
- 规则升级 `b4-3`，指纹 `collision=world-v3`；旧认证不冒充新内容，不生成 passed。
