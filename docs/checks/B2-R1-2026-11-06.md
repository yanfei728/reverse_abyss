## 1. R1 · 默认入口

- `index.html` 现在是短塔入口：`<meta http-equiv="refresh" content="0; url=short.html">` + 手动链接；双击 `file://`/本地 HTTP 都进入当前短塔。
- 旧原型完整保存在 `legacy.html`，从 `index.html` 和短塔页都有明确“旧原型(历史)”链接；旧数据、旧池与浏览器存储未动。
- `editor.html`、`devplay.html` 的“回游戏”仍指向 `index.html`，现在落到短塔。开发/正式区别不变；正式池为空时仍提示制作/认证，不抽未认证草稿。
- `tools/test_engine.mjs` 的入口脚本检查改到 `legacy.html`，并新增“index 默认 short/不再启动旧 main/legacy 明确历史”检查；`browser_b2` 从 `index.html` 启动并验证自动跳转。

## 2. R2 · 对象坐标/接触

- `FloorInstance.updateActiveObjects()` / `playerOverlap()` 现在先把 Player 世界坐标转换到实例局部，再与 `objectBox()` 的局部框比较；`feetOnTop`、弹簧、门、浮石、地刺、火球、齿轮全部走同一坐标。模板 `row/col/path` 与实例 `rx/ry` 仍是局部，Player 仍是世界坐标，未写回模板。
- 门：扩大 6px 接触容差，正常侧面/顶面接近即可触发；触发后显示与实心判定一起移除，本局不恢复，事件一次。
- 浮石：落地当步 `warning` 且仍承重；0.5s 后 gone，gone 1.6s；暂停冻结 timer；恢复前检查局部玩家占位，占位则延后，不夹人。
- 样例修正（仅新 B2 模板）：`normal-2` 浮石格去掉叠压静态瓦片；`normal-1` 火球格去掉叠压平台；`normal-3` 齿轮路径移到无平台遮挡的 row 5。`js/b2-samples.js` 已重生成。
- 代表路线：`normal-2` 从入口平台向上到 row 8 平台，门在 col 5、浮石在 col 4；`normal-1` 弹簧在下方、火球在 col 7 row 6；`normal-3` 地刺/齿轮沿 row 5。上层 origin 例如 `(90,-540)`，用于非零原点回归。

## 3. R3 · 标准试玩技能

- `rules.js` 升 `rulesVersion=b2-2`；`standard-v1` 改为 `allowSkill:true`、初始活动光环 0、初始剩余冷却 20 秒、无休整回复。旧 `b2-1` 回执/认证不能再发布/抽选；旧草稿保留，需重新实际标准通关。
- `standard.js` 接 `K` 到同一个 `GameSession.pressSkill()`；HUD 从“无光环”改为“技能冷却 Xs / 光环 Xs / 就绪(K)”；光环激活时画可见半径。CD 归零后能实际施放、清火球、跨层保留、暂停冻结。
- `test_b2` 去掉 `allowSkill===false` 错误断言，改为“开局 K 失败 → 20 模拟秒后 K 成功、14/20 秒”的实际行为。
